## 学習された提案

- **D の提案**: `[2, 0, 0, 3, 0, 0]` — 自分に3個、**A に2個**
- **B の提案**: `[1, 4, 0, 0, 0, 0]` — 自分に4個、**A に1個**

ベースライン（提案者2個+3票を1個ずつ買収）と違い、提案者は3〜4個と
多めに取り、買収先は実質 A のみ。

## 考察

- **権力を均等にしても分配は均等にならない**。しかも突出するのは
  提案回数が最少（10回）の A。実際の提案機会と取り分はほぼ無相関。
- **「A への朝貢」が権力なしでも発生**。この非対称の源泉として最も
  有力なのは**事前学習（固定順一般解）の遺産**である。固定順の一般解では
  否決後の提案者は「生存者中で最も若いインデックス」＝実質 A であり、
  A の継続価値だけが突出して高い。この事前知識から出発したため、
  「A だけは0個では賛成しない（脅しが信用される）」という地位が
  ランダム順環境でもそのまま定着し、各提案者は A にだけ宝石を払う。
  つまり**現実の権力（提案機会）が平等でも、共有された歴史的な地位
  （事前知識）が実質的な身分として機能し続ける**。
  ※事前学習なしの対照実験は未実施のため、この因果は状況証拠に基づく解釈。
- **提案者の取り分はベースラインより大きい**（2個 → 3〜4個）。
  権力集中がないぶん「次の提案者」が特定の強者に固定されず、
  買収すべき相手が A 1人に絞られるため、残りを自分に回せる。
- **政治は安定的**。ベースラインで見られた大規模な体制動揺
  （死亡率57%級の危機)はなく、死亡率はほぼ全区間0%
  （エポック9300に E の死亡率10%の小さな動揺が1回）。
  一発可決率もほぼ常に100%。**権力格差がないほうが政治は安定する**
  という結果になった。
- 実行時間は約3.3時間で、ベースライン（約5.5時間）より短い。
  否決ラウンドの少なさ（エピソード長がほぼ常に最短の7）と整合的。
