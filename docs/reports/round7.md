# 第7ラウンド実験レポート: 方策収束の直接測定（試行29〜32）

## 目的と設計

第6ラウンド（[`round6.md`](round6.md)）で、これまで安定性の指標に使ってきた
「首位の交代回数」が**首位の分離度と交絡している**ことが判明した。
引き離していれば交代は起きにくく、団子なら何度でも入れ替わるため、
権力構造や L が違う実験どうしを比較できない。

本ラウンドは**計測系を改修したうえで、保留した論点を測り直す**。

### 計測系の改修

`train.py` に `record_proposals()` を追加し、メトリクス記録の各点で
**「全員生存・自分が提案者」の局面で各エージェントが貪欲に選ぶ分配案**を
CSV に記録するようにした（列 `prop_A` 〜 `prop_F`）。

- 報酬にも順位にも依存しないため、分離度の交絡を受けない
- 「提案の変更回数」がそのまま方策の揺れの回数になる
- `scripts/analyze_convergence.sh` が方策収束エポックと変更回数を報告する

### 実験の配置

| 試行 | 設定 | 測り直す論点 |
|---|---|---|
| 29 | L=5・一強 | 「L=5 は特異的に安定」は方策の水準でも成り立つか |
| 30 | **L=5・均等** | 「収束には権力集中が要る」の判定（第6ラウンドで判定不能だった） |
| 31 | L=20・一強 | 「L=20 は非単調な例外」は方策の水準でも現れるか |
| 32 | L=100・一強 | 高罰則域の方策の揺れ（比較の基準点） |

共通設定: 事前学習なし、7000エポック、メトリクス評価100エピソード、シード42。
試行29・31・32 は重み `[50,1,1,1,1,1]`、試行30 は `[1,1,1,1,1,1]`。
**L と重み以外はすべて同一**である。

試行29・31・32 はそれぞれ試行16・18・11 と同一設定の再実行にあたるが、
本ラウンドでは報酬指標ではなく方策指標で評価する点が異なる。

生データ: `result/result_29.txt` 〜 `result_32.txt`、
`log/log_metrics_29.csv` 〜 `32`（`prop_*` 列を含む）、
グラフ `files/plots/log_metrics_29.png` 〜 `32.png`。

## 試行29: L=5・一強

報酬指標は試行16とほぼ一致した（A の全期間平均 +1.94、首位交代0回、
レジーム収束140）。以下は新しい方策指標による測定である。

| 指標 | 値 |
|---|---|
| 取り分構成の変更（6体まとめて） | 88回 / 99区間 |
| **A（提案の91%を担う）の変更** | **25回** |
| B / C / D / E / F の変更 | 33 / 37 / 33 / 41 / **58**回 |

### 計測系の2つの改良点が、走らせて初めて分かった

**改良1: 受け取り手の識別子を落とす必要がある。**
最初の実装は提案ベクトルの完全一致で変更を数えたため、98回/99区間という
ほぼ全点変更という結果になった。実際の系列を見ると

```
3-0-0-1-1-0 → 3-0-1-0-1-0 → 3-0-1-0-1-0 → 4-0-1-0-0-0 → 3-0-1-0-1-0
```

のように、**A が3個を確保して2人に1個ずつ配る形は保ったまま、
配る相手だけが入れ替わっている**。誰が買収されるかは同一設定の独立実行でも
総入れ替えになることが第3ラウンドで分かっている以上、これを方策の変更と
数えるべきではない。「自分の取り分 + 他者の取り分の多重集合」に正規化した
（88回に減少）。

**改良2: エージェント別に数える必要がある。**
正規化しても6体まとめてでは88回と高いままだった。内訳を見ると、
**提案の91%を担う A が25回で最も安定し、ほとんど提案しない F が58回で
最も不安定**である。めったに提案しないエージェントは提案行動の学習信号を
ほとんど受け取らないため、方策が揺れ続ける。6体をまとめて数えると、
この未学習のノイズが主要な提案者の安定性を覆い隠してしまう。

### 分かったこと

- **「L=5 は特異的に安定」は報酬の順位についての話であって、
  方策についての話ではなかった**。本プロジェクトで最も収束して見えた
  この実験でも、主要な提案者 A の方策は99区間中25回変わっている。
- 一方で **A が他の5体より明確に安定している**ことは測定できた
  （25回 対 33〜58回）。方策指標はエージェント別に見れば機能する。
- 25回が低いのか高いのかは、他の L との比較ではじめて言える。
  試行31（L=20）・試行32（L=100）が基準を与える。

## 試行30: L=5・均等（第5ラウンドの仮説の判定）

| エージェント | 提案の割合 | 提案の変更回数 |
|---|---|---|
| A | 約16.7% | **17回** |
| B | 約16.7% | 33回 |
| C | 約16.7% | 21回 |
| D | 約16.7% | 30回 |
| E | 約16.7% | 23回 |
| F | 約16.7% | 23回 |
| **平均** | | **24.5回** |

### 試行29（L=5・一強）との対照

| | L=5・一強（試行29） | L=5・均等（試行30） |
|---|---|---|
| **首位の交代回数（旧指標）** | **0回** | **26回** |
| **提案の変更回数（平均）** | **37.8回** | **24.5回** |
| 主要な提案者の変更回数 | A（91%）: 25回 | 6体平均: 24.5回 |
| ほとんど提案しない者の変更回数 | B〜F（各1.8%）: 33〜58回 | 該当なし |

### 判定: 「収束には権力集中が要る」は支持されない

- **旧指標（首位交代）では一強が圧倒的に安定（0回 対 26回）に見えたが、
  方策指標では逆に均等のほうが安定している**（平均24.5回 対 37.8回）。
  第5ラウンドの仮説は、方策の水準では支持されない。
- 旧指標の差は第6ラウンドで特定したとおりの見かけであった。均等構造は
  全員の取り分が横並び（幅0.17）なので argmax が絶えず入れ替わるだけで、
  方策が揺れていたわけではない。
- **方策の安定性を決めていたのは権力の集中ではなく、
  そのエージェントの提案行動がどれだけ学習信号を受け取るかである**。
  均等構造では6体全員が約16.7%ずつ提案するので全員がそれなりに学習され
  （17〜33回）、一強構成では A 以外が1.8%しか提案しないため
  ほとんど学習されない（33〜58回）。一強の平均が悪いのは、
  この未学習の5体に引きずられているためである。
- 主要な提案者どうしを比べると、A（91%・25回）と均等構造の各体
  （16.7%・平均24.5回）はほぼ同等である。**提案機会を5倍以上与えても
  方策の安定性は改善しない**という点も、あわせて観察された。

### 方策の水準では、どの設定も収束していない

本ラウンドで測った2実験とも、最も安定したエージェントでも99区間中17回は
提案を変えている（方策収束はいずれも未収束）。
**この実験系は方策の水準では収束しない**というのが、
交絡のない指標で測った結論である。差は程度の問題にとどまる。

## 試行31: L=20・一強

| エージェント | 提案の変更回数 |
|---|---|
| **A（提案の91%）** | **59回** |
| B / C / D / E / F | 70 / 77 / 79 / 64 / 73回 |
| **平均** | **70.3回** |

### 試行29（L=5・一強）との対照 — L の効果が方策の水準で確認できた

| | L=5（試行29） | L=20（試行31） |
|---|---|---|
| **A の提案の変更回数** | **25回** | **59回**（2.4倍） |
| 6体平均 | 37.8回 | 70.3回（1.9倍） |
| 首位の交代回数（旧指標） | 0回 | 17回 |

**L=20 は L=5 より方策が明らかに不安定である。** 主要な提案者 A の変更回数が
25回から59回へ2.4倍に増えており、これは順位の入れ替わりやすさとは無関係な
量である。第4ラウンド以来「L が大きいほど落ち着かない」と述べてきたが、
**交絡のない指標でこれを確認できたのは今回が初めて**である。

一方で、第4〜6ラウンドで問題になった「L=20 が L=30 より不安定」という
非単調性については、L=30 を新指標で測っていないため本ラウンドでは判定できない。

### 副産物: 同一シードの再実行は完全に一致する

試行31は試行18（第4ラウンドの `r4_L20.json`）と設定もシードも同一である。
報酬側の指標を突き合わせると**すべて完全に一致した**。

| 指標 | 試行18 | 試行31 |
|---|---|---|
| 首位の交代回数 | 17回 | 17回 |
| 分配収束 / 許容差 | 280 / 1.36 | 280 / 1.36 |
| 死亡なしの記録点 | 76/100 | 76/100 |
| 全期間平均 | A:+0.99 B:+1.07 C:+0.55 D:+0.53 E:+0.84 F:+0.52 | 同一 |

- **学習パイプラインはシードを固定すれば完全に再現する**。並列環境
  （`SubprocVectorEnv`）を使っているため非決定性を疑っていたが、
  実際には決定的だった。
- したがって、これまで「独立再現」と呼んできた実験の差は**すべてシードに
  由来する**ものであり、実行ごとのランダム性ではない。
- **今回追加した提案の記録は学習の軌道を乱していない**。
  記録は勾配を伴わない前向き計算のみで、探索に使う乱数を消費しないためである。
  新旧の指標を同じ実験について安全に比較できることが裏づけられた。
