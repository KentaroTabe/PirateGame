# 第26ラウンド実験レポート: エージェント数を6未満から測る（試行112〜123）

## 目的

`findings.md` の未着手項目「**エージェント数・宝石数を変えた場合の一般性**」に着手する。

宝石数は第25ラウンドで扱った（L を固定して 5個/10個 を比較し、
**効いているのは L の絶対値**と決着）。残るのは**エージェント数**である。

### 6未満から始める理由

エージェント数は行動空間と必要票数を同時に変えるため、
いきなり大きくすると計算量が増えるうえ、比較の解釈も難しくなる。

| エージェント数 | 分配案の数 | 必要票 |
|---|---|---|
| **3** | **21** | 2 |
| **4** | **56** | 2 |
| **5** | **126** | 3 |
| 6（既知） | 252 | 3 |
| 7 | 462 | 4 |
| 8 | 792 | 4 |

**6未満は行動空間が小さく、速く回せる。**
n=3・4・5 を測れば n=6 の既知値と合わせて4点になり、
**そこから n=7 を予測して当てにいける。**

曲線を後から当てはめるのではなく、**事前予測を立てて検証する形**にする。

## 設計

| 試行 | エージェント数 | シード |
|---|---|---|
| 112〜115 | **3** | 42・7・13・99 |
| 116〜119 | **4** | 42・7・13・99 |
| 120〜123 | **5** | 42・7・13・99 |

共通: 宝石5個・**L=20**・一強 `[50,1,…]`・罰1.0・提案者が最後に投票・
票数観測あり・事前学習なし・7000エポック。

**L=20 を選んだのは非飽和域だから**である（第25ラウンドで確認）。
既知の n=6 の値は **+0.0473**（n=4、試行49・109・110・111）。

## 事前の予測

**エージェント数が減るほど感応度は上がる**と予測する。

理由は2つある。

1. **1票の重みが増す。** n=3 なら必要票2のうち自分の1票が半分を占めるが、
   n=6 なら必要票3のうちの1票である。**自分の投票が結果を変える確率が高いほど、
   投票の Q 値に勾配が届く**（第16ラウンドで、投票者の報酬は自分の投票では
   変わらず可決の成否を通してしか効かないと確認した）。
2. **一人あたりの宝石が多い。** 宝石5個を3人で分ければ、1個の差は
   取り分の大きな割合を占める。6人ならその半分である。

**予測値**: n=6 の +0.047 に対し、n=5 は +0.06 前後、n=4 は +0.08 前後、
n=3 は +0.10 以上。

**外れた場合も含めてそのまま記録する。**

## 判定と次の段取り

1. n=3・4・5 を測り、n=6 と合わせて4点の傾向を見る
2. **その傾向から n=7 の値を予測し、レポートに書く**
3. 第27ラウンドで n=7 を4シード走らせ、予測が当たるか確かめる

**2 の予測を先に書くことが本ラウンドの主眼**である。
当てはめた曲線が n=7 で外れるなら、傾向は外挿できないと分かる。

## 測る指標

- **感応度**（`tools/vote_sensitivity.py`）
- 集計は `scripts/summarize_vote_sensitivity.py`、
  比較は `scripts/compare_cells.py`

生データ: `result/result_112.txt` 〜 `result_123.txt`。

## 第26ラウンドの統合結論

### 1. 結果

| エージェント数 | 4本の値 | **平均** | **範囲** |
|---|---|---|---|
| **3** | 0.069・0.086・0.072・0.069 | **+0.0743** | 0.069〜0.086 |
| **4** | 0.073・0.069・0.065・0.063 | **+0.0677** | 0.063〜0.073 |
| **5** | 0.066・0.064・0.096・0.074 | **+0.0752** | 0.064〜0.096 |
| **6** | 0.044・0.044・0.061・0.041 | **+0.0473** | 0.041〜0.061 |

| 比較 | U | 両側 p | 範囲の重なり |
|---|---|---|---|
| **n=3 対 n=6** | **0** | **0.029** | **なし** |
| **n=4 対 n=6** | **0** | **0.029** | **なし** |
| **n=5 対 n=6** | **0** | **0.029** | **なし** |
| n=3 対 n=4 | 3 | 0.171 | あり |
| n=3 対 n=5 | 7 | 0.800 | あり |
| n=4 対 n=5 | 5 | 0.486 | あり |

**n=3・4・5 は互いに区別できず、3つとも n=6 とは分離する。**
形は「滑らかな減少」ではなく、**n=5 と n=6 の間の段差**である。

### 2. 事前予測は向きだけ当たり、形は外れた

予測は「n が減るほど感応度が上がる（n=5 で +0.06、n=4 で +0.08、n=3 で +0.10 以上）」
だった。

- **向き**（n が小さいほど高い）は当たった
- **形**は外れた。n=3・4・5 はどれも +0.068〜+0.075 で**平坦**であり、
  予測した単調増加にはなっていない
- **値**も外れた。n=3 は +0.074 で、予測の +0.10 に届かない

### 3. 予測の根拠にした「1票の重み」は成り立たない

予測の第1の根拠は「必要票のうち自分の1票が占める割合」だった。
必要票は n=3・4 で **2**、n=5・6 で **3** である。

**この境界（n=4 と n=5 の間）では段差が出ていない**（p=0.486）。
一方、**必要票が変わらない n=5 と n=6 の間で段差が出ている**（p=0.029）。

**根拠は否定された。**

### 4. 「一人あたりの宝石」も成り立たない（既存データから）

第2の根拠は「一人あたりの宝石が多いほど1個の差が効く」だった。
宝石5個なら n=3 で 1.67個、n=6 で 0.83個である。

しかし**第25ラウンドに、これを直接否定するデータがある。**

| 条件 | 一人あたりの宝石 | 感応度 |
|---|---|---|
| **n=3・宝石5個** | **1.67** | **+0.074** |
| **n=6・宝石10個** | **1.67** | **+0.037** |

**一人あたりの宝石が同じでも、エージェント数が違えば感応度は倍近く違う。**
効いているのは**エージェント数そのもの**であって、一人あたりの宝石ではない。

### 5. n=7 の予測（第27ラウンドで検証する）

上記より、**エージェント数が直接効いており、n=5 と n=6 の間に段差がある**。
第25ラウンドの n=6・宝石10個（+0.037）も低い側にある。

**予測: n=7 は n=6 と同水準かそれ以下、具体的には +0.030〜+0.050 に入る。**

**反証条件**: n=7 の4本が **+0.063 以上**（n=3〜5 の範囲）に来たら、
この予測は外れである。その場合「n=6 だけが低い」という別の形になり、
段差の説明を作り直す必要がある。

判定は第25ラウンドまでと同じく、**順位検定と範囲の両方を示して**行う。
