# 実験レポート: 階段型 `[32, 16, 8, 4, 2, 1]`（試行9）

## 実験概要

| 項目 | 値 |
|---|---|
| 権力ウェイト | `[32, 16, 8, 4, 2, 1]`（全員が異なる権力の完全階層） |
| 提案機会の期待割合 | A 51% / B 25% / C 13% / D 6% / E 3% / F 2% |
| 命の重さ L | 100 |
| 学習エポック | 10000 |
| 生データ | `result/result_9.txt`, `log/log_eval_9.txt`, `log/log_metrics_9.csv` |
| 学習曲線 | `files/plots/log_metrics_9.png` |

構図: 上から下まで切れ目のない権力の階段。「次の提案者」候補が層をなす。

## 評価結果（100エピソード・貪欲方策）

| エージェント（重み） | 平均報酬 | 死亡率 | 提案回数（可決率） |
|---|---|---|---|
| A (32) | **+0.08** | 0% | 45回 (100%) |
| B (16) | +1.13 | 0% | 29回 (100%) |
| C (8)  | +1.12 | 0% | 13回 (100%) |
| D (4)  | +0.83 | 0% | 9回 (100%) |
| E (2)  | +0.31 | 0% | 2回 (100%) |
| F (1)  | **+1.53** | 0% | 2回 (100%) |

全エピソードが一発可決（平均提案回数 1.00）。**権力序列と報酬序列がほぼ逆転**。

## 学習された提案

- **A の提案**: `[0, 0, 2, 1, 0, 2]` — **自分に0個**、C に2個・D に1個・F に2個
- **B の提案**: `[0, 3, 0, 1, 1, 0]` — 自分に3個、D・E に1個ずつ、**A に0個**

最強の A は提案機会の51%を持ちながら、取り分を全て他者に譲る。

## 学習の経過

エポック6000までは平穏（A も1個台後半を確保する時期あり）。
**エポック6000〜8500に「革命期」**: A の提案が繰り返し否決され死亡率が
スパイク（生データで50%超）、A の平均報酬は-8以下まで崩落。
この punishment を経て A は「全面譲歩」を学習し、以後は自分0個の提案で
安定する。エポック9000〜9600には B にも同様の小規模な粛清が起きる
（終盤10%区間の B -2.60 はこの危機に引きずられた値）。

## 考察

- **L=100 では権力（提案機会）はリスク資産に転化する**。提案は一発の否決で
  -100 を食らう行為であり、提案機会が多い者ほど「殺され得る回数」が多い。
  切れ目のない階層では「A を殺しても B が、B を殺しても C が」と
  次の提案者候補が層をなすため、下位層の継続価値＝拒否の脅しが
  常に信用され、上位者は譲歩を強いられる。
- **結果は権力序列のほぼ逆転**。ほぼ提案できない F（2%）が最大の取り分
  +1.53 を得て、過半の提案権を持つ A が +0.08 で最下位。
  試行3（1000エポック・二頭型）で観察された「弱者の強請」の極端形が、
  完全階層では長期学習後も安定して残る。
- **一強型（試行8）との対照が鮮明**。同じ「A が過半の提案権」でも、
  権力の裾野が絶壁（50:1）なら A は8割を収奪し、階段（32:16:8:…）なら
  A は全てを差し出す。**収奪を可能にするのは権力の絶対量ではなく、
  「自分の後継候補が育っていないこと」**（否決後の世界が全員にとって
  無価値であること）。
- 革命期以外は死亡率0%・一発可決率ほぼ100%で、表面上の政治は平穏。
  駆け引きの帰結はもっぱら分配案の中身に現れる。
- 実行時間は約3.5時間（18:49〜22:18）。
