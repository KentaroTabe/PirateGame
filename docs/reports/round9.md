# 第9ラウンド実験レポート: 過剰賛成票ペナルティの検証（試行37〜40）

## 目的と設計

事前実験（[`round0.md`](round0.md)）で、**可決時に必要最小票を超えた賛成1票に
つき提案者の報酬から引く**というペナルティ（`excess_vote_penalty`）を課すと、
**提案者が自分の提案に反対票を投じる**という異常行動が観察されたと記録されている。
海賊ゲームでは提案者も投票者の一人なので、自分が反対に回れば超過分を1票減らして
ペナルティを軽減できるためである。

現在のパイプラインでは、この設定は**全40試行で 0.0 のまま一度も検証していない**
（固定順一般解がこのペナルティを想定していないため、事前学習と整合させる目的で
無効にしていた）。第9ラウンドでこれを検証する。

| 試行 | ペナルティ | L | 重み | 狙い |
|---|---|---|---|---|
| 37 | **1.0** | 5 | 一強 | 異常行動が再現するか（方策が最も安定する L=5 で） |
| 38 | **2.0** | 5 | 一強 | ペナルティを強めると行動も強まるか |
| 39 | **1.0** | 100 | 一強 | 高罰則域でも現れるか |
| 40 | **1.0** | 5 | 均等 | 権力構造によらず現れるか |

共通設定: 事前学習なし、7000エポック、メトリクス評価100エピソード、シード42。
比較の基準は試行29（ペナルティ 0.0・L=5・一強・シード42）である。

### 計測系の追加

異常行動を目視ではなく数値で捉えるため、`eval.py` に
**「提案者が自分の提案に投じた票」の集計**を追加した。
評価100エピソードを通じて「提案者が自分の提案に反対した割合」を
`result/result_n.txt` に記録する。ペナルティ 0.0 の設定では
0% になるはずであり、そこからの乖離が異常行動の強さになる。

生データ: `result/result_37.txt` 〜 `result_40.txt`、
`log/log_eval_37.txt` 〜 `40`（投票の詳細ログ）、
`log/log_metrics_37.csv` 〜 `40`。

## 試行37: ペナルティ1.0・L=5・一強

### 異常行動はほとんど再現しなかった

**提案者が自分の提案に反対した割合は 1.9%（2/106）**にとどまった。
事前実験で記録された「提案者が自分の提案に反対する」という顕著な行動は、
少なくともペナルティ1.0・L=5・一強の条件では再現していない。

なお比較対象の試行29 は本指標の追加前に実行したため、
**ペナルティ 0.0 での自己反対率は未測定**である。1.9% がペナルティに
由来するのか元々の雑音なのかは、この試行だけでは切り分けられない。

### 予期しなかった効果: ペナルティが独裁者を富ませた

同一条件でペナルティのみを変えた試行29 との比較。

| 指標 | 試行29（罰 0.0） | 試行37（罰 1.0） |
|---|---|---|
| **A の平均報酬** | **+1.82** | **+2.88** |
| A の提案回数（可決率） | 90回（100%） | 96回（100%） |
| C の平均報酬 / 死亡率 | +1.00 / 0.0% | **-0.18 / 4.0%** |
| F の平均報酬 / 死亡率 | +0.94 / 0.0% | **-0.10 / 2.0%** |
| C・F の提案の可決率 | 100% | **0%** |
| 平均提案回数 | 1.00 | 1.06 |

**超過賛成票を罰する規則が、最強の提案者 A の取り分を +1.82 から +2.88 へ
1個以上増やした。** 詳細ログ（3エピソード分）で機構が確認できる。

| | 試行29（罰 0.0） | 試行37（罰 1.0） |
|---|---|---|
| A が自分に取る宝石 | 2個 | **3個** |
| A が買収する人数 | 3人 | **2人** |
| 可決時の超過賛成票 | 0 | 0 |

A は罰則下で**買収相手を3人から2人に絞り、浮いた1個を自分の取り分にした**。
過剰な支持を罰する規則は、提案者に「最小限の連合だけを買え」と教え、
その節約分はそのまま提案者の懐に入る。**支持の買い占めを抑制する規則が、
むしろ独裁者の分け前を増やす方向に働いた。**

同時に、ほとんど提案しない C と F は提案がすべて否決されるようになり
（可決率 100% → 0%）、死亡率が 0.0% から 4.0% / 2.0% に上がって
平均報酬がマイナスに転じた。**罰則は弱い提案者の交渉余地を削った。**

ただし超過賛成票は両条件とも 0 であり、**罰則は実際にはほとんど発動していない**
（詳細ログ3エピソードの範囲）。差は罰を受けた結果ではなく、
罰を避けるように方策が変わった結果である。
