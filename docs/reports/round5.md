# 第5ラウンド実験レポート: 再現・閾値の細分化・一般性（試行21〜24）

## 目的と設計

第4ラウンド（[`round4.md`](round4.md)）で残った3つの課題に対応する。
第1ラウンドで「1つの条件から一般化して結論を誤る」失敗を犯しているため、
本ラウンドは**再現1本・細分化1本・一般性2本**という配分にした。

| 試行 | 設定 | 対応する課題 |
|---|---|---|
| 21 | **L=50・シード7**（試行19の独立再現） | 荒れ具合53%がシード依存でないか |
| 22 | **L=30** | 権力の符号の閾値（L=20〜50）の細分化 |
| 23 | **L=10・階段重み** `[32,16,8,4,2,1]` | L の結論の一般性（別構造1） |
| 24 | **L=10・均等重み** `[1,1,1,1,1,1]` | L の結論の一般性（別構造2） |

共通設定: 事前学習なし、7000エポック、メトリクス評価100エピソード。
試行21・22は重み `[50,1,1,1,1,1]`、試行23・24は L=10 に固定して重みを変える。

**試行23・24の狙いを明確にしておく**。第4ラウンドまでの L に関する結論は
すべて一強構成でしか確かめていない。L=10 は一強構成で
「収束する・権力は資産（A が3個を確保）」という最も鮮明な結果を出した水準なので、
ここを別の権力構造に移して同じことが起きるかを見る。

- **階段 `[32,16,8,4,2,1]`**: L=100 では権力序列と報酬序列が逆転した構造
  （試行9・15）。L=10 で逆転が消えるなら、逆転は L の産物だと言える。
- **均等 `[1,1,1,1,1,1]`**: 権力構造がない対照。L=10 で収束するなら、
  収束は権力の集中とは無関係に L だけで決まることになる。

生データ: `result/result_21.txt` 〜 `result_24.txt`、
`log/log_eval_21.txt` 〜 `24`、`log/log_metrics_21.csv` 〜 `24`、
グラフ `files/plots/log_metrics_21.png` 〜 `24.png`。

主指標は**死亡込みの全期間平均**。ただし L をまたぐ比較では
順位・提案の中身・収束性という L 非依存の指標を使う
（[`round4.md`](round4.md) の「指標について」参照）。

## 試行21: L=50 の独立再現

| エージェント（重み） | 最終評価 | 全期間平均（死亡込み） |
|---|---|---|
| A (50) | **-2.18**（死亡率8.0%） | **-0.09**（**6位・最下位**） |
| B (1)  | -1.90（死亡率4.0%） | +0.34 |
| C (1)  | -1.02（死亡率4.0%） | **+0.56**（1位） |
| D (1)  | -0.98（死亡率2.0%） | +0.55 |
| E (1)  | +1.06 | +0.43 |
| F (1)  | +1.02 | +0.34 |

**学習された提案**: A: `[2,0,1,0,1,1]` — 自分に2個、C・E・F に1個ずつ。

### 試行19（L=50・シード42）との比較

| | 試行19（シード42） | 試行21（シード7） | 再現したか |
|---|---|---|---|
| **A の順位** | **6位（最下位）** | **6位（最下位）** | **✅ 再現** |
| A の全期間平均の符号 | 負（-1.56） | 負（-0.09） | **✅ 再現** |
| A の全期間平均の大きさ | -1.56 | -0.09 | **❌ 17倍の開き** |
| **A の提案** | `[2,0,0,1,1,1]` | `[2,0,1,0,1,1]` | **✅ 一致**（自分に2個・3人に1個ずつ） |
| 死亡を含む記録点 | **53%** | **37%** | △ 大小関係は再現、値は不一致 |
| 首位の交代回数 | 9回 | 12回 | ✅ 同程度 |
| レジーム収束 | 未収束 | 未収束 | ✅ 再現 |

### 考察

- **「L=50 で権力が負債に転じる」は再現した**。A は両方の実行で
  6体中最下位、全期間平均は負である。第4ラウンドで示した
  「権力の符号の閾値は L=20 と L=50 のあいだ」という結論は保たれる。
- **ただし損失の大きさは再現しない**（-1.56 vs -0.09、17倍差）。
  L=50 付近では**順位と符号は語れるが、量は語れない**。
- **荒れ具合の非単調性は弱いかたちで再現した**。死亡を含む記録点は
  53% と 37% で、いずれも隣接する L=20（24%）や L=100（19%）より高い。
  「L=50 付近が最も荒れる」という向きは保たれるが、
  53% という数値そのものは1本目に固有だった。
- **提案の中身は完全に一致した**（自分に2個・3人に1個ずつ）。
  第4ラウンドで見た「L は方策の内容ではなく維持しやすさを変える」は
  ここでも成り立つ。

### 最終評価が危機のさなかを捉えた初めての例

試行21の最終100エピソード評価は、**本プロジェクトで初めて
平穏でない状態を捉えた**。A の死亡率8.0%、B・C の提案可決率20%、
平均提案回数1.18（他の実験はほぼ1.00）である。
これまで「最終評価は平穏な瞬間のスナップショットにすぎない」と
繰り返し述べてきたが、逆に危機の瞬間を捉えることもあるという実例になった。
**評価が平穏に見えるかどうか自体が運である**という理解が正しい。

## 試行22: L=30

| エージェント（重み） | 最終評価 | 全期間平均（死亡込み） |
|---|---|---|
| A (50) | **+2.86** | **+1.52**（**1位**） |
| B (1)  | +0.98 | +0.48 |
| C (1)  | +0.98 | +0.76 |
| D (1)  | +0.02 | +0.61 |
| E (1)  | +0.12 | +0.55 |
| F (1)  | +0.04 | +0.58 |

**学習された提案**: A: `[3,1,1,0,0,0]` — **自分に3個**、B・C に1個ずつ。
可決に必要な2票だけを買う最小限の買収（L=10 と同じ形）。

| 指標 | 値 |
|---|---|
| 首位の交代回数 | 9回 |
| **レジーム収束** | **3850**（以後45%が安定） |
| 分配収束 | 3360（以後52%が安定） |
| **秩序収束** | **1190**（以後83%が安定） |
| 死亡なしの記録点 | 74/100 |
| A の死亡危機 | 1回（エポック1050〜1500）。以後7000まで平穏 |

### 考察: 符号の閾値は L=30 と L=50 のあいだに絞られた

L=30 で A は **+1.52 の1位**、つまり権力はまだ資産である。
L=50 の2本はいずれも A が最下位・負だったので、
**権力の符号の閾値は L=30 と L=50 のあいだ**にある
（第4ラウンドの「L=20〜50」から絞り込めた）。

### 訂正: 収束の閾値という言い方は成り立たない

第4ラウンドで「収束の閾値は L=10 と L=20 のあいだ」と書いたが、
L=30 が収束したことでこの言い方は成り立たなくなった。

| L | 収束したか | 首位交代 |
|---|---|---|
| 5（2本） | ✅ ✅ | 0回・0回 |
| 10 | ✅ | 3回 |
| **20** | **❌** | **17回** |
| **30** | **✅** | 9回 |
| 50（2本） | ❌ ❌ | 9回・12回 |
| 100（2本） | ❌ ❌ | 19回・23回 |

**収束した L=30 が、収束しなかった L=20 より罰則が重い**。
単調な閾値では説明できない。可能性は2つある。

1. L=20 の未収束はシードの引きによるもので、L≦30 では概ね収束する。
2. 収束性は L に対して本当に非単調である。

**現状のデータでは区別できない**。第4ラウンドの L=50 再現実験で、
同一設定でも死亡を含む記録点が53%と37%、A の平均が -1.56 と -0.09 と
大きくばらつくことが判明している以上、**各 L につき1本で閾値を語ったのは
踏み込みすぎだった**。L=20 と L=30 の再現実験が要る。

一方で**符号については両側に2本ずつの裏づけがある**
（L=50 は2本とも負、L=5 は2本とも正）ため、こちらの結論は保てる。

## 試行23: L=10・階段重み `[32,16,8,4,2,1]`

| エージェント（重み） | 最終評価 | 全期間平均（死亡込み） |
|---|---|---|
| A (32) | **+1.41** | **+1.30**（**1位**） |
| B (16) | +1.05 | **+0.79**（2位） |
| C (8)  | +0.73 | +0.64 |
| D (4)  | +0.71 | +0.68 |
| E (2)  | +0.66 | +0.65 |
| F (1)  | +0.44 | +0.62 |

**学習された提案**: B: `[1,2,0,0,1,1]` — 自分に2個、A・E・F に1個ずつ。
A: `[2,1,1,1,0,0]` — 自分に2個、B・C・D に1個ずつ。
**提案者が自分の取り分を確保している**。

### 試行15（同じ階段重み・L=100）との対照

全期間平均（死亡込み）の順位:

| 重み | L=100（試行15） | L=10（試行23） |
|---|---|---|
| A (32) | **-0.97（6位・最下位）** | **+1.30（1位）** |
| B (16) | +0.08（5位） | +0.79（2位） |
| C (8)  | +0.36（4位） | +0.64（5位） |
| D (4)  | +0.65（1〜3位） | +0.68（3位） |
| E (2)  | +0.65（1〜3位） | +0.65（4位） |
| F (1)  | +0.65（1〜3位） | +0.62（6位） |

| | L=100 | L=10 |
|---|---|---|
| 権力序列と報酬序列 | **ほぼ完全に逆転** | **ほぼ一致** |
| 提案者の取り分 | B は0個・A は2個 | B も A も2個 |
| 首位の交代回数 | 24回 | 11回 |
| レジーム収束 | 未収束 | **4130**（以後41%が安定） |

### 考察: 「権力序列の逆転」は L=100 の産物だった

- **階段構造でも L を下げると逆転が消え、報酬序列は権力序列にほぼ一致する**。
  L=100 で最下位だった最強の A（-0.97）が、L=10 では首位（+1.30）になり、
  最弱の F は首位グループから最下位へ移った。
- 第1ラウンドの結論4「階段では権力序列と報酬序列が逆転する」は、
  第3ラウンドで事前学習なしでも成り立つことを確認していたが、
  **L=100 という条件に依存していた**ことがここで判明した。
  権力構造の性質ではなく、やはり L の産物である。
- **一強構成で見た L の効果は階段構造にも一般化する**。
  「低い L では権力が資産になる」「低い L では振動が収まる」は
  権力構造を変えても成り立った（首位交代24回→11回、
  レジームは未収束→4130エポックで収束）。
- **ただし収束の度合いは一強構成より弱い**。一強・L=10（試行20）は
  首位交代3回でレジーム・分配・秩序のすべてが収束したのに対し、
  階段・L=10 はレジームのみ収束し、分配と秩序は未収束である。
  提案者が6体に分散するぶん、揺らぎの発生源が多いためと解釈できるが、
  これは推測であり未検証。
