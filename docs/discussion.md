# 考察: 罰と権力構造のもとで、何が投票行動を決めているのか

[`results.md`](results.md) にまとめた結果を、**なぜそうなるのか**という観点から解釈する。
解釈にはコード（`env.py`・`solver.py`・`train.py`・`tools/vote_sensitivity.py`）の読解と、
既存の学習ログ・モデルから本書のために計算した値を用いる。

本書の記述は、根拠の強さで3種類に分けて示す。

| 表示 | 意味 |
|---|---|
| **［結果］** | `results.md` で確立済みの結論 |
| **［事後解析］** | 本書のために既存ログ・モデルから計算した値。**事前登録していないので、確立した結論ではない** |
| **［仮説］** | コードと理論からの推論。**未検証** |

---

## 要旨

1. **合理的な基準解では、L は結果を一切変えない。** 観測された L の効果はすべて、
   学習する主体どうしの食い違い（提案の否決）に **L という値段がつくこと**で生じている。
2. **権力が負債に変わるのは、否決の頻度が L を上げても下がらず、その費用を提案者だけが負うからである。**
   L=100 で A の報酬が落ちる分の約86%は、生き残ったときの取り分の減少ではなく死亡による損失である。
3. 票数観測・宝石数・エージェント数についての結論は、**走査局面の75〜88%が対局では決して現れない観測**
   である指標に依存している。数値は正しいが、**「投票者が取り分を気にしなくなった」とは読めない。**
4. 事前知識の効果が「一強では埋もれる」のは、権力構造のせいというより、
   **L=100 の死亡損失のばらつきが報酬を覆い隠しているせい**かもしれない。
   一強でも、生き残ったときの A の取り分には事前学習の差がはっきり出ている（事後解析）。
5. 全体を通じて、**構造変数（L・権力の集中）は「ありうる帰結の幅」を決め、
   どの帰結が実現するかはシードや事前知識といった履歴が決める。**
   「条件をまたいだ一般化は成立しない」（`results.md` 第6節）のは、このためだと考えられる。

## 1. 合理的な基準では L は効かない。では、なぜ効くのか

### 1.1 基準解の検算 ［事後解析］

固定順の一般解ソルバー（`solver.py`）で、6体・宝石5個のゲームを L だけ変えて解いた。

| L | 全員生存時の価値（A〜F） | A の最適案 | 可決できない部分ゲーム |
|---|---|---|---|
| 5 | [3, 0, 1, 0, 1, 0] | [3, 0, 1, 0, 1, 0] | 0 件 |
| 20 | [3, 0, 1, 0, 1, 0] | [3, 0, 1, 0, 1, 0] | 0 件 |
| 30 | [3, 0, 1, 0, 1, 0] | [3, 0, 1, 0, 1, 0] | 0 件 |
| 50 | [3, 0, 1, 0, 1, 0] | [3, 0, 1, 0, 1, 0] | 0 件 |
| 100 | [3, 0, 1, 0, 1, 0] | [3, 0, 1, 0, 1, 0] | 0 件 |

**L を20倍にしても、何も変わらない。**

理由はソルバーの構造にある。投票者の「否決したときの価値」は
`continuation_value()` が返す部分ゲームの価値 $V(S \setminus \{p\})$ であり、
これが L に依存するのは**部分ゲームのどこかで提案が可決できないとき**だけである。
このゲームでは可決できない部分ゲームが1つもないので、
**$-L$ は均衡経路の外にしか現れず、誰の価値にも入り込まない。**

ランダム順の基準解は計算していない（**未確認**）。ただし同じ論理——
「どの部分ゲームでも可決できる案がある限り、合理的な提案者は否決される案を出さない」——は
提案順の決まり方によらず成り立つ。

**帰結**: `results.md` 第1節の L の効果（感応度・符号・収束）は、
**すべて合理的な基準の外側にある。** それは学習の過程——
学習途中の主体の提案が、ときどき否決されること——から生じているはずである。

### 1.2 A の報酬が L で落ちる理由は「死ぬ頻度 × L」である ［事後解析］

A の1エピソードの報酬は、死ねば $-L$、生き残れば 0〜宝石数のいずれかである
（`env._resolve_vote()`）。したがって

$$
\text{平均報酬} = (1-d)\,g - d\,L
$$

が厳密に成り立つ（$d$: 死亡率、$g$: 生き残ったときの平均取り分）。
`scripts/decompose_agent_reward.py` で、一強・事前学習なしの L 掃引を分解した。

| L | n | 死亡率 $d$ | 生き残ったときの取り分 $g$ | 死亡による損失 $dL$ |
|---|---|---|---|---|
| 5 | 2 | 1.0〜3.7% | 1.96〜2.01 | 0.05〜0.19 |
| 10 | 2 | 0.1〜1.9% | 1.86〜2.15 | 0.01〜0.19 |
| 20 | 4 | 1.0〜5.6% | 1.26〜1.97 | 0.20〜1.12 |
| 30 | 4 | 0.9〜1.9% | 1.12〜1.80 | 0.26〜0.58 |
| 50 | 2 | 3.0〜5.6% | 1.33〜1.47 | 1.51〜2.81 |
| 100 | 2 | 5.7〜7.5% | 0.48〜1.44 | 5.70〜7.46 |

読み取れることは3つある。

- **死亡率は L を上げても下がらない。** むしろ L=50〜100 の方が高い。
  死ぬことの値段が20倍になっても、学習者は死ぬ頻度を減らせていない。
- **生き残ったときの取り分は緩やかに減る**（約2.0 → 約1.0）。
  L が高いと提案者はより多くを譲る（`results.md` の「全員妥協」）。
- **報酬の落ち込みの大半は死亡損失である。** L=5 から L=100 への落ち込み（約7.5）のうち
  **約86%が死亡損失**、約14%が取り分の減少である。L=50 でも約77%が死亡損失である。

なお、この死亡率は学習中の各記録点で**貪欲方策（ε=0）どうしを対戦させて**測ったものである
（`train.collect_political_metrics()`）。したがってこれは探索の乱数による否決ではなく、
**その時点の各主体の方策が互いに噛み合っていないこと**による否決である。

### 1.3 権力が負債になる仕組み ［仮説］

否決の費用 $-L$ を負うのは提案者だけである（`env.py:263`）。
一強構成では A が提案の91%を担うので、**否決の費用をほぼ A だけが負う。**

- 提案機会が多い ＝ **食い違いの費用を負う機会が多い**
- 食い違いの頻度 $d$ は L で下がらない
- したがって L が上がると、A の損失 $dL$ は L にほぼ比例して増える
- 生き残ったときの取り分（約1.5）を損失が上回るところで、**権力の符号が反転する**

表から見ると、損失が取り分に並ぶのは L=30 と L=50 のあいだであり、
**`results.md` 1.3 の符号の閾値（L=30〜50）と一致する。**

立法交渉の標準的なモデルである Baron–Ferejohn モデルでは、提案権を得ることは有利である
（提案が否決されても提案者は罰を受けず、時間が過ぎるだけだから）。
本実験で提案権が不利に反転するには、**2つの条件が同時に要る**。

1. 否決の費用を**提案者だけ**が負うこと（ゲームの性質）
2. 否決が**実際に起きる**こと（学習者の性質。合理的な主体なら起きない）

**権力の負債化は、ゲームだけでも学習者だけでも生じず、両者の組み合わせで生じる。**

### 1.4 閾値の付近でばらつきが最大になる理由 ［事後解析で一部を裏づけ］

報酬は $(1-d)g - dL$ なので、**シードごとの死亡率のばらつきが L 倍されて報酬に乗る。**

第28ラウンドの一強・事前学習なし（L=100、4シード）では

| 量 | 4本の範囲 | 幅 |
|---|---|---|
| A の全期間平均報酬 | -5.29〜-0.55 | **4.7** |
| 死亡による損失 $dL$ | 1.07〜5.77 | **4.7** |
| 生き残ったときの取り分 $g$ | 0.48〜0.95 | 0.47 |

であり、**報酬のシード間のばらつきは、ほぼすべて死亡率のばらつきである。**

閾値の付近（L=20〜30）では、取り分（約1.1〜2.0）と死亡損失（約0.2〜1.1）が同じ桁になる。
そこでは**そのシードで何回食い違いが起きたか**によって符号が決まる。
`results.md` 1.3 で L=20・30 の符号が「混在」になったこと、
第31ラウンドで L=20 の谷が確立しなかったこと（L=20 の4本は死亡率の幅が 1.0〜5.6% と、
L=30 の 0.9〜1.9% より広かった）は、この読みと矛盾しない。

### 1.5 なぜ死亡率は L を上げても下がらないのか ［仮説］

2つの仮説が考えられる。現状のデータでは区別できない。

**H1: 食い違いの頻度は、独立学習者の非定常性で決まる。**
各主体は他者の方策が動き続ける環境で学習するので、互いの方策は常にずれている
（独立学習者の非定常性はマルチエージェント強化学習で古くから知られている）。
このずれの頻度は学習の力学で決まり、**賭け金の大きさでは決まらない。**

**H2: L が大きいと、Q ネットワークの学習そのものが乱れる。**
報酬は正規化していない（`train.py` は `DQNPolicy` に `reward_normalization` を渡していない）。
しかも各主体は**1つのネットワークで提案と投票の両方の Q 値を出す**（`network.Net` の出力は
分配案の数＋賛成＋反対）。L=100 では提案行動の目標値が $-100$ 付近まで広がり、
0〜5 の幅しかない投票行動の学習を二乗誤差の上で圧倒する。
L=50〜100 で死亡率がむしろ高いことは、H2 と整合的である。

**区別する実験**: **すべての報酬を $1/L$ 倍して**学習する（第8節の検証1）。
戦略的にはまったく同じゲームなので、H1 なら結果は変わらず、H2 なら L の効果が縮む。

## 2. 投票が対価に反応しなくなる理由（`results.md` 1.1・1.2）

### 2.1 否決は投票者にとっても危険である ［仮説］

否決されるとゲームは続き、**投票者自身が次の提案者に選ばれうる**
（`env._select_next_proposer()`）。提案者になれば、1.2 で見た食い違いの費用を負う。
つまり投票者にとって、反対票は

- 「提示された取り分を捨てる」だけでなく
- 「自分が提案者となって $-L$ を負うかもしれない局面に進む」

ことを意味する。後者の費用は L に比例する。
**L が大きいと、取り分がいくらであっても賛成しておく方が安全になり、
投票が取り分に反応しなくなる。**

この費用の大きさは、「次の提案者になる確率」と「提案したときに否決される確率」の積に L を掛けたものである。
後者（提案1回あたりの否決率）は測っていない（**未確認**）。とくに一強構成では、
A 以外は提案する機会が少なく、**提案1回あたりの否決率は A より高い可能性がある**
（未確認）。

1.5 の H2（学習の乱れ）も、同じく「高い L で投票の学習が粗くなる」ことを予測する。
こちらも検証1 で区別できる。

### 2.2 効くのが「L の絶対値」で「L/宝石数」ではない理由 ［仮説］

2.1 の費用は**宝石の総数に比例しない**。宝石を 5個 から 10個 にしても、
投票者が判断するのは「取り分が1個増えるかどうか」であり、
その1個と比べられるのは「提案者になって $-L$ を負う危険」である。

したがって効くのは **L を宝石1個の単位で測った大きさ**、つまり L の絶対値である。
宝石の総数（比の分母）は、投票の判断に直接は入らない。
`results.md` 1.2（L=20 で宝石5個と10個が区別できない）は、この読みと整合的である。

**予測**: 危険の項が宝石1個より小さくなる**低い L**（例えば L=5）では、
宝石の総数が効き始めるはずである。

### 2.3 補足: 感応度は「値段」ではなく「しきい値の有無」を測っている ［定義からの帰結］

感応度の走査（`tools/vote_sensitivity.py`）は、各局面で投票者の取り分を 0→1→…→5 と1個ずつ上げ、
賛否が切り替わった回数を数える。

- どこかに**しきい値**（「k 個以上なら賛成」）がある投票者は、
  **k がいくつであっても**切り替わりは1回である
- **何個でも賛成**（または何個でも反対）する投票者だけが、切り替わり0回になる

つまり感応度は「しきい値を持つかどうか」を測っており、
**しきい値の高さ（その投票者の値段）は測っていない。**
「安く売る」（低いがゼロではない値段）は感応度には現れない。
現れるのは「0個でも賛成する」ことだけである。

この点は第4節の読みに効いてくる。

## 3. 感応度が測っているもの——票数観測の結果の読み直し（`results.md` 3・1.2・5）

### 3.1 走査局面の大半は、対局では決して現れない ［事後解析］

投票順は環境が決めており（`env._build_voting_order()`: 生存者の固定順。
`proposer_votes_last` なら提案者だけが末尾）、ある投票者がある提案者のもとで投票するとき、
**「投票済み人数」はただ1通りに決まる。**

一方、感応度の走査は票数観測ありの設定で、
［これまでの賛成数, 投票済み人数］の**全組み合わせ**を走査する（6体なら21通り）。
`scripts/scan_reachability.py` で、対局で到達しうる局面の割合を数えた。

| 使われた結論 | 設定 | 人数 | 到達可能な局面 |
|---|---|---|---|
| 3.1・3.2（票数観測の効果） | L=5・L=100 の票数観測セル | 6 | **16.7%**（1050/6300） |
| 1.2（L の絶対値か比か） | L=20・宝石5／10個 | 6 | **14.3%** |
| 5（エージェント数） | L=20・n=3 | 3 | 25.0% |
| 〃 | n=4 | 4 | 20.0% |
| 〃 | n=5 | 5 | 16.7% |
| 〃 | n=6 | 6 | 14.3% |
| 〃 | n=7 | 7 | 12.5% |

**票数観測ありの走査では、局面の75〜88%が、ネットワークが学習中に一度も見たことのない観測である。**
そこでの出力は外挿にすぎない。

票数観測なしの走査（ベースライン・乱数セル）では、この問題は起きない
（票の途中経過を走査しないため）。

### 3.2 結論ごとの影響

**`results.md` 3.1（票数観測は感応度を下げる）**
比べているのは「全局面が到達可能な走査」と「83%が到達不能な走査」である。
感応度が下がったことには、少なくとも3つの説明が成り立つ。

| 説明 | 内容 | 対局中の投票は取り分に鈍くなったか |
|---|---|---|
| (a) 予測力のある特徴 | 投票者が「通りそうか」を見て取り分を軽視する（`results.md` の読み） | **鈍くなった** |
| (b) 合理的な非ピボタル性 | 到達可能な局面の中には勝敗がすでに決まった局面がある（例: 賛成がすでに3票）。そこでは合理的な投票者にとって賛否は無差別である | 決着局面でのみ鈍くなった |
| (c) 外挿 | 到達不能な局面では、出力が取り分に反応する理由がない | **鈍くなっていない**（測定上だけの低下） |

**現在のデータでは (a)・(b)・(c) を区別できない。**

**`results.md` 3.4（効くのは情報であって次元数ではない）**
乱数セルの走査は票の途中経過を含まず、到達不能な局面を持たない。
したがってこの対照は「入力の次元が増えたこと」を否定するが、**(c) は否定しない。**
「情報」とは「投票者がその情報を使っている」ことかもしれないし、
「走査に反実仮想の票数が混ざったこと」かもしれない。

**`results.md` 3.3（票数観測はシード間のばらつきを縮める）と第30ラウンドの二分割**
到達不能な局面での出力がシードによらずほぼ一定なら、ばらつきは機械的に縮む。
票数観測セルで半分同士の差が極めて小さかったこと（0.0003〜0.0086）も、同じ理由で説明できる。

**`results.md` 1.2（L の絶対値）** 比べた2群は人数が同じで、到達可能な割合も同じ（14.3%）である。
**比較としては公平**であり、読み方への注意にとどまる。

**`results.md` 5（エージェント数）** 到達可能な割合が**人数とともに単調に下がる**（25% → 12.5%）。
人数をまたいだ比較は、走査の中身の違いと交絡している。
単調な交絡なので n=6 だけの谷は作れないが、**仮に人数の効果が見えていても解釈できなかった。**
「検出できなかった」という否定的結果の注意書きを強める。

**`results.md` 1.1（L の効果）** には票数観測なしの条件で確立したものが含まれており、
この問題の影響を受けない。**本研究で最も頑健な結果は L の効果である。**

### 3.3 直し方 ［提案］

走査を**到達可能な局面だけ**に絞り、さらに「勝敗が未決着の局面」と「決着済みの局面」に分けて
感応度を出す。**既存のモデルで計算でき、再学習は要らない**（第8節の検証2）。

- (a) なら、到達可能・未決着の局面でも差が残る
- (b) なら、差は決着済みの局面に集中する
- (c) なら、到達可能な局面に絞ると差が消える

## 4. 事前知識はどの経路で効くのか（`results.md` 2）

### 4.1 事前知識の中身

事前学習の目標値は固定順ソルバーから作られる（`pretrain.py`）。
ソルバーでは、否決された後の提案者は**常に生存者のうち最若番**である（`solver.value()` は
`proposer = min(alive)`）。つまり事前知識は「**A 以外の提案が否決されたら、次は A が提案する**」
という信念を全員に埋め込む。

実際のランダム順ゲームで、A 以外の提案者が否決されたあとに A が次の提案者になる確率は

| 重み構成 | A が次の提案者になる確率 |
|---|---|
| 均等 `[1,1,1,1,1,1]` | 1/5 = **20%** |
| 一強 `[50,1,1,1,1,1]` | 50/54 = **93%** |

である。**事前知識は、均等では大きく誤っており、一強では「誰が次か」についてほぼ正しい。**

### 4.2 均等重み: 効果の約3分の2は「他の5体が死ぬ頻度」から来ている ［事後解析］

第29ラウンドの8本（均等・L=100）を分解した。

| | 事前学習あり | なし |
|---|---|---|
| A の全期間平均 | 0.964 | 0.743 |
| A の生き残ったときの取り分 | 1.073 | 0.869 |
| A の死亡率 | 0.11% | 0.13% |
| **他の5体の全期間平均** | **0.149** | **0.571** |
| **他の5体の死亡率** | **0.64%** | **0.26%** |

A優位度の差 0.64 のうち、**A 自身の上昇は 0.22（34%）、他の5体の低下が 0.42（66%）** である。
他の5体の低下のほぼ全部（0.38）は、**死亡率が 0.26% から 0.64% に上がったこと**による。

ただし、**どの経路も単独では n=4 で確立しない**
（他の5体の報酬 U=1・p=0.057、他の5体の死亡率 U=2・p=0.114、A の取り分 U=4・p=0.343）。
確立しているのは、それらを合わせた A優位度だけである（U=0・p=0.029）。

**解釈 ［仮説］**: 事前知識によって A の「否決後の価値」が過大に見積もられているので、
A は安い提案に反対しやすい。その結果、**A を十分に買わなかった他の提案者の案が否決され、
その提案者が死ぬ。** A 自身の死亡率は変わらない（A は提案者でないときに反対しても死なない）。
これは元の訂正1 の文言「A の反対だけは信用される」と整合的である。
ただし A が実際に反対する頻度は測っていない（**未確認**）。

**なぜ学習で是正されないのか ［仮説］**: 均等重みでは全員が対称なので、
「A を買う」のと「B を買う」のとで提案者の損得は変わらない。
**損得に差がないので、誤った信念から離れる勾配が生じない。**
事前知識は、同じ値打ちの解のどれを選ぶかを決める**目印**として働いている。
これはゲーム理論でいう**焦点**（Schelling）の役割と同じである。

### 4.3 一強: 効果は「取り分」に出ているが、死亡損失に隠れている ［事後解析］

`results.md` 2 では、一強では事前学習の効果が確立しなかった（A の全期間平均で p=0.686）。
しかし同じ8本を分解すると、**生き残ったときの A の取り分には明確な差がある。**

| | 事前学習あり | なし |
|---|---|---|
| **A の生き残ったときの取り分** | **1.37〜2.32**（平均1.79） | **0.48〜0.95**（平均0.61） |
| A の死亡率 | 2.0〜4.5% | 1.1〜5.8% |
| A の全期間平均 | -2.71〜+0.28 | -5.29〜-0.55 |

取り分は**範囲が重ならず、U=0・p=0.029** である。
一方、全期間平均は死亡損失（$dL$、1〜6）のばらつきに支配されており、
取り分の差（約1.2）はその中に埋もれる。

> **注意**: これは事後解析である。本書では A・他の5体について、報酬・死亡率・取り分など
> 複数の派生量を見たうえでこの差を見つけた。**多重比較の問題があり、確立した結論ではない。**
> 仮説を立てるための観察として扱う。

この観察が正しければ、3つのことが言える。

1. **`results.md` 2 の「一強では事前知識の寄与は埋もれる」を埋めているのは、
   権力構造そのものではなく、L=100 の死亡損失のばらつきかもしれない。**
2. 4.1 の「一強では事前知識がほぼ正しいので効かない」という説明は、**この観察と矛盾する。**
   事前知識は「誰が次か」だけでなく、**固定順での各投票者の値段**（ほとんどの投票者の
   否決後の価値は0か1なので、安く買える）も埋め込んでいる。その値段が一強でも残り、
   A はより多くを手元に残せている、と読める。
3. 第28ラウンドで撤回した訂正2 の機構「被支配者が安く売る」は、
   **値段の水準としては本当かもしれない。** 撤回の根拠の1つだった感応度に差がないことは、
   2.3 のとおり値段の水準については何も言わない。撤回したのは報酬についての主張
   （A +1.18 対 -5.25）であり、それがシード42 のばらつきだったことは変わらない。

**確かめ方**（第8節の検証3・4）: 投票者が受け入れる最小の宝石数（値段）を直接測る指標を作り、
第28ラウンドのモデルで事前登録のうえ比べる。また、死亡損失が小さい L=5 で一強×事前学習を走らせれば、
報酬の上でも差が見えるはずである。

## 5. 自己反対は「同じ値打ちの解のどちらに落ちるか」である（`results.md` 4）

過剰賛成票ペナルティを避ける2つのルートは、**提案者にとってまったく同じ値打ち**である。
どちらでも罰はゼロになる。

- 自己反対ルート: 必要票ぶんを買い、自分は反対して超過票を消す
- 決定票ルート: 必要票より1票少なく買い、自分の賛成で可決させる

値打ちが同じなので、**提案者の損得はどちらを選ぶ理由も与えない。**
どちらに落ちるかは、他の5体が超過票を供給するかどうか——
つまり**他者の方策（シードに依存する）**——が決める（`results.md` 4.2）。
自己反対率が 0〜8% と 90〜100% に二分されること（4.1）は、
**各主体が同じ値打ちの2つの慣習のどちらかに落ち着いている**ことを示している。

票数が見えて最後に投票できる場合にだけ自己反対が現れること（4.3）も、この読みと合う。
超過票があるかどうかを見られなければ、自己反対ルートはそもそも選択肢にならない。

これは 4.2 の事前知識と同じ構図である。**損得の差がない選択肢のあいだでは、
学習は履歴によって一方に落ち着き、構造はそれを選ばない。**

## 6. 統合: 構造は「ありうる帰結の幅」を決め、履歴が「どれになるか」を決める

ここまでの考察を並べると、1つの構図が見える。

| 現象（`results.md`） | 構造が決めていること | 履歴（シード・事前知識）が決めていること |
|---|---|---|
| 収束には低い L と権力の集中が要る（1.4） | 両方がそろうと、ありうる帰結が1つに近づく | そろわないと、どの帰結の周りを揺れるか |
| 個体名を含む結論は低 L でしか再現しない（6） | 高 L では誰を買っても値打ちが同じ | 誰が寵臣になるか |
| 事前知識は均等重みでだけ効く（2） | 均等では買収先の選択が同じ値打ち | どの買収先に落ち着くか（事前知識が目印になる） |
| 自己反対は二値に分かれる（4） | 2つのルートが同じ値打ち | どちらのルートに落ちるか |
| A優位度のばらつきは閾値付近で最大（1.3） | 取り分と死亡損失が同じ桁になる | そのシードで何回食い違ったか |

**構造（L・重み構成・観測の設計）は、同じ値打ちの帰結がどれだけあるかを決める。
その中からどれが実現するかは、学習の履歴が決める。**

Baron–Ferejohn モデルの定常均衡でも、提案者が**どの**最小勝利連合を組むかは均衡では決まらず、
無作為に選ばれる。本実験で「誰が買われるか」が再現しなかったこと
（`results.md` 第6節の個体名の制約）は、この理論上の不定性がそのまま学習にも現れたものと読める。

さらに本実験には、**履歴の影響を増幅する装置**がある。
1.4 で見たとおり、L は食い違いの回数のばらつきを L 倍して報酬に乗せる。
高い L では、報酬に基づく指標のシード間のばらつきは、ほとんどが履歴で決まる。

**`results.md` 第6節の「条件をまたいだ一般化は原則として成立しない」は、ここから説明できる。**
効果の大きさ自体が条件ごとに違うだけでなく、**効果を覆い隠す雑音の大きさ**が
L と構造によって大きく変わる。同じ効果が、ある条件では見え、別の条件では埋もれる
（4.3 の事前学習の効果は、その候補である）。

## 7. 限界

1. **学習アルゴリズムは1つだけである。** 独立学習の Double DQN・固定のハイパーパラメータ
   （隠れ層 [128,128]、ε=0.1、学習率とバッファは自動調整）でしか確かめていない。
   第1節の中心的な主張（L の効果は食い違いの値段である）は、
   **学習者の性質に依存する主張なので、別のアルゴリズムでは変わりうる。**
2. **高い L では学習が収束していない。** 評価は常にスナップショットであり、
   全期間平均は学習の過渡期を含む。
3. **感応度の走査は、構成した局面の上で測っている。** 票数観測ありでは大半が到達不能である（3.1）。
   票数観測なしでも、対局で訪れる頻度の重みはつけていない。
4. **本書の事後解析は事前登録していない。** 4.2・4.3 の分解は、結果を見たあとで派生量を選んでいる。
5. **検出力が低い。** 多くの比較が n=4 であり、中程度の効果は見えない（`results.md` 第7節）。
6. **ゲームが小さい。** 6体・宝石5個が中心で、L の掃引は一強構成に限られる。
7. **ランダム順の合理的基準解は計算していない。** 1.1 の論証のうちランダム順への拡張は推論である。

## 8. 考察から導かれる検証

本書の読みが正しければ、次の結果が出るはずである。いずれも事前に予測を書いてから行う。

| # | 検証 | 必要なもの | 本書の読みが正しい場合 | 読みが外れる場合 |
|---|---|---|---|---|
| 1 | **すべての報酬を $1/L$ 倍して学習する**（戦略的に同じゲーム） | 新規の学習 | H1 なら L の効果は変わらない。H2 なら縮む（1.5） | ―（どちらかが支持される） |
| 2 | **到達可能な局面だけで感応度を測り直す**（未決着／決着済みに分ける） | **既存モデルのみ** | 票数観測の効果が到達可能・未決着の局面でも残る（3.3 の (a)） | 差が消える → `results.md` 3.1 は外挿の産物 |
| 3 | **値段（受け入れる最小の宝石数）の指標を作り、第28ラウンドのモデルで比べる** | **既存モデルのみ** | 一強で事前学習ありの投票者の値段が低い（4.3） | 差がない → 4.3 は偶然 |
| 4 | **一強 × 事前学習あり／なしを L=5 で走らせる** | 新規の学習 | 死亡損失が小さいので、報酬の上でも事前学習の差が見える（4.3） | 見えない → 「死亡損失が隠している」説は外れ |
| 5 | **低い L で宝石数を 5個／10個 と変える** | 新規の学習 | 危険の項が小さい低 L では宝石数が効く（2.2） | 効かない → 2.2 の説明は不十分 |
| 6 | **探索率を下げる・学習を長くして死亡率を下げる** | 新規の学習 | 死亡率が下がれば権力の負債化が弱まり、符号の閾値が高い L へ動く（1.3） | 動かない → 負債化は食い違い以外から来ている |

検証2・3 は**再学習なしで実行できる**ので、最初に行う価値が高い。
とくに検証2 は `results.md` 3.1〜3.4 の読み方を左右する。
