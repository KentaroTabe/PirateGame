# 第31ラウンド実験レポート: L=20 の谷は本物か（試行156〜159）

## 目的

第30ラウンドで、既存ログから A優位度（A の全期間平均 − 他5体の平均）を
計算し直したところ、**L=20 だけが両隣より低い**という単調性の破れが見えた。

| L | 試行 | A優位度 |
|---|---|---|
| 5 | 16・17 | +1.349 / +1.092 |
| 10 | 20・27 | +1.358 / +1.232 |
| **20** | **18・25** | **+0.288 / -0.435** |
| 30 | 22・26 | +0.928 / +0.701 |
| 50 | 19・21 | -1.874 / -0.532 |

これは**順位では見えなかった**。順位で見ると L=20 は「2位・6位」、
L=30 は「1位・1位」で、「L が上がるほど順位が落ちる」という
単調な読みに収まってしまう。**連続量にした瞬間に破れが見えた。**

ただし各 L につき **n=2 しかない。**
第26・27ラウンドで「n=6 だけが谷」に見えたものが n=7 で再現しなかった前例がある。
**n=4 対 n=4 にして確かめる。**

## 設計

| 試行 | L | シード |
|---|---|---|
| 156・158 | **20** | 13・99 |
| 157・159 | **30** | 13・99 |

共通: 6体・宝石5個・一強 `[50,1,1,1,1,1]`・罰0.0・事前学習なし・7000エポック
（`configs/r4_L20.json` と同一で、L とシードだけを変える）。
既存の 18・25（L=20、シード42・7）と 22・26（L=30、シード42・7）に足して
**n=4 対 n=4** にする。**対で走らせる。**

## 事前の予測（実験前に記録・変更しない）

1. **L=20 の4本の平均は L=30 の4本の平均より低い。**
2. **ただし範囲は重なり、差は確立しない。**
   各セルの幅がすでに 0.7 以上あるためである。

**反証条件**: 範囲が重ならなければ、**谷は本物である。**

## 指標

**A優位度**（`scripts/summarize_agent_rewards.py` の `A優位度` 列）。
判定は順位検定と範囲の両方を示して行う。

### シード13 の対で、範囲が重なった

| | 3本の値 | 範囲 |
|---|---|---|
| **L=20** | +0.288・-0.435・**+0.544** | -0.435〜+0.544 |
| **L=30** | +0.928・+0.701・**-0.205** | **-0.205〜+0.928** |

**-0.205 〜 +0.544 の区間が重なっている。**
範囲の重なりは標本を足しても消せない（すでに観測された値は取り消せない）ので、
**残り1対を待たずに予測2 が確定し、「谷は確立しない」と判定できる。**

さらに**シード13 の対では向きが逆転している**
（L=20 が +0.544、L=30 が -0.205）。

### 第26・27ラウンドと同じ経過をたどった

| | 谷に見えたもの | 追加したもの | 結果 |
|---|---|---|---|
| 第26・27ラウンド | n=6 の感応度 | n=7（4シード） | 谷は再現せず |
| **本ラウンド** | **L=20 の A優位度** | **シード13・99** | **範囲が重なった** |

**A優位度は同一条件で 1.1 以上の幅で散らばる**（L=30 で -0.205〜+0.928）。
L 間の 0.4〜0.5 程度の差は、この幅に埋もれる。

残り1対は、平均の向きと順位検定を確定させるために走らせる。
