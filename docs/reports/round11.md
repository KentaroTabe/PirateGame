# 第11ラウンド実験レポート: 自己反対を生む条件の切り分け（試行46〜48）

>

> 成り立たない。** 第13ラウンドの試行53 で、そのセルをシード7 で再実行したところ
> **自己反対率は 92.0%** だった（原著の試行43 はシード42 で 0.0%）。
> 例外セルではなく、**シードによって両極に振れるセル**である。
>

> 各セルが n=1 である以上、根拠を失っている。
> 一方、**統合結論2（自己反対には提案者が票数を観測でき、かつ十分に遅く
> 投票することの両方が要る）は、個体単位の証拠（試行48 で F が18回中18回、
> 他の5体が0回）に基づいており、影響を受けない。**
> 詳細は [`round13.md`](round13.md) を参照。

## 目的

第10ラウンド（[`round10.md`](round10.md)）で、環境に投票の途中経過の観測を
足すと**自己反対が 38.0% まで現れる**ことが分かった（試行45）。
しかし試行45 は、自己反対が 0.0% だった試行43 から**2つの条件を同時に
変えていた**ため、何が効いたのかを特定できていない。

| | 試行43 | 試行45 |
|---|---|---|
| **L** | **100** | **5** |
| **権力ウェイト** | **一強** | **均等** |
| 投票順・観測 | 順番＋観測 | 順番＋観測 |
| **自己反対率** | **0.0%** | **38.0%** |

本ラウンドは、この2×2 の空欄を埋めて交絡を解く。

## 設計

| 試行 | L | 重み | 投票順 | 観測 | 位置づけ |
|---|---|---|---|---|---|
| 46 | **5** | **一強** | 最後 | 票数 | **L だけを試行43 から変える** |
| 47 | **100** | **均等** | 最後 | 票数 | **権力構造だけを試行43 から変える** |
| 48 | 5 | 均等 | **従来** | 票数 | 試行45 から投票順を外す（順番は本当に不要か） |

共通設定: 罰1.0、事前学習なし、7000エポック、評価100エピソード、シード42。

### 判定の仕方

試行43（L=100・一強）が 0.0%、試行45（L=5・均等）が 38.0% という2点に対し、
空欄を埋めた結果で原因が決まる。

| 試行46（L=5・一強） | 試行47（L=100・均等） | 結論 |
|---|---|---|
| **高い** | 低い | **L が効いている**（否決の代償が小さいほど出る） |
| 低い | **高い** | **権力構造が効いている**（提案者が分散するほど出る） |
| 高い | 高い | どちらも単独で十分 |
| 低い | 低い | **両方が揃って初めて出る**（交互作用） |

試行48 は、第10ラウンドで「`proposer_votes_last` は単独では無効」と分かった
のを受け、**観測だけで自己反対が出るか**を確かめる。
出れば、必要な変更は観測1つに絞れる。

### L が効くという仮説（事前の予測）

自己反対を学習するには、探索の途中で**実際に反対して否決される**経験が要る。
その代償は L=5 なら -5 だが L=100 なら -100 であり、
**高い L では方策が固まる前に消える**と考えられる。

この仮説が正しければ **試行46 で自己反対が現れ、試行47 では現れない。**

### 詳細ログを増やした

試行45 では自己反対が 38% あったのに、詳細ログが3エピソードしかなく
**実際の投票列を1件も観察できなかった。**
本ラウンドは `eval_verbose_episodes` を **20** にして、
行動が出た場合に中身を確認できるようにしている。

生データ: `result/result_46.txt` 〜 `result_48.txt`、
`log/log_eval_46.txt` 〜 `48`、`log/log_metrics_46.csv` 〜 `48`。
評価ログの解析には `scripts/analyze_selfvote.py` を使う。

なお本ラウンドのモデルは、第10ラウンド末に修正した保存処理により
**中身のある状態で保存される**（それ以前の45個は空である）。
`scripts/reevaluate.sh` で学習をやり直さずに再評価できる。

## 試行46: L=5・一強・順番＋観測

### 自己反対率 98.0%。一強では L が決定的（ただし全体の結論ではない）

**提案者が自分の提案に反対した割合は 98.0%（98/100）。**
試行43 から **L を 100 から 5 に変えただけ**で、0.0% から 98.0% に飛んだ。

| | 試行43 | **試行46** |
|---|---|---|
| **L** | **100** | **5** |
| 権力ウェイト | 一強 | 一強 |
| 投票順・観測 | 順番＋観測 | 順番＋観測 |
| **自己反対率** | **0.0%** | **98.0%** |

**権力構造は同じ（どちらも一強）なので、差は L だけによる。**

> **訂正（試行47 の後）**: 当初ここに「効いていたのは L だった」と書いたが、
> **一強の列に限った話**だった。均等では L=100 で 62.0%、L=5 で 38.0% と
> **向きが逆転する**。L 単独では説明できない。下の試行47 の節を参照。

### 実際の投票列

詳細ログを20エピソードに増やしたので、今回は中身を確認できる。

```
提案 [2, 0, 1, 1, 0, 1]   ← A は2個を自分に、C・D・F へ1個ずつ
B 賛成 / C 賛成 / D 賛成 / E 反対 / F 反対
A（提案者・最後）→ 👎 反対
[判定] 賛成: 3 / 生存者: 6 → 可決、超過票 0
```

**A は3人を買収して3票を確保し、自分は反対に回っている。**
自分が賛成すれば賛成4票となり超過1票分の罰を受けるが、
反対すればちょうど必要な3票で可決し、罰はゼロになる。

20エピソード中20件すべてが同じ形で、超過票は全件 0 だった。
報酬の合計もちょうど 5.00 で、**罰は1つも支払われていない。**

これは事前実験（[`round0.md`](round0.md)）が記述したメカニズムそのものであり、
第10ラウンドの試行45（38.0%）よりはるかに徹底している。

### なぜ L が効くのか

自己反対は**自分の票を数に入れられない**戦略である。
可決に必要な3票を**他人だけで揃えなければならない。**

- **L=5（試行46）**: 買収した3人のうち1人が裏切れば賛成2票で否決され、
  A は -5 を負う。**この程度なら賭けられる。**
- **L=100（試行43）**: 同じ裏切りが -100 になる。
  だから A は**自分が決定票になる**提案（買収2人＋自分の賛成＝3票）を選び、
  他人の裏切りに依存しない形にした。

**自己反対の代償は L に比例する。** 高い L では、罰1つを節約するために
死の危険を他人の手に委ねることが割に合わない。

### ただし A にとっては損な解である

同じ L=5・一強で環境設定だけがない**試行37**（第9ラウンド）と比べると、
A の取り分はむしろ**減っている。**

| | 試行37（設定なし） | 試行46（順番＋観測） |
|---|---|---|
| A の平均報酬 | **+2.88** | **+1.80** |
| A が自分に取る宝石 | **3個** | **2個** |
| A が買収する人数 | **2人** | **3人** |
| A 自身の票 | 賛成 | **反対** |
| 可決時の超過賛成票 | 0 | 0 |
| 払われた罰/エピソード | ほぼ 0 | **0.00** |

**どちらも罰をゼロにしているが、試行37 の方が宝石を1個多く残している。**
買収2人＋自分の賛成で3票を作る方が、買収3人＋自分の反対より安い。

つまり**自己反対は罰の回避策としては正しいが、最善ではない。**
観測と投票順を与えたことで、A はより高い報酬の解（試行37 の形）から
**劣った解に移ってしまった。**

第10ラウンドで「自己反対が普通は現れないのは、それが劣った解だからである」と
整理したが、本試行はその裏返しの証拠になる。
**L を下げて自己反対を可能にすると、実際に劣った解に落ち着く。**

## 試行47: L=100・均等・順番＋観測

### 62.0%。試行46 の「L が効いている」という結論は成り立たない

**自己反対率は 62.0%（62/100）。** L=100 でも高い割合で現れた。
2×2 が埋まった結果は次のとおり。

| | **一強** | **均等** |
|---|---|---|
| **L=100** | **0.0%**（試行43） | **62.0%**（試行47） |
| **L=5** | **98.0%**（試行46） | **38.0%**（試行45） |

**L だけでも権力構造だけでも説明できない。**

- 一強では L が決定的（0.0% → 98.0%）
- **均等では L の向きが逆転し、幅も小さい**（62.0% → 38.0%）

試行46 の時点で「効いていたのは L だった」と書いたが、**これは一強の列に
限った話**であり、全体の結論としては誤りだった。ここで訂正する。

### 現れないのは「一強かつ L=100」の1セルだけ

4セル中3セルで自己反対が現れている。**例外は一強・L=100 のみ**である。

このセルの特殊性は2つある。

1. **提案者が固定されている**。A が提案の9割を担うので、
   **提案側の学習信号が A に集中する**（均等では各自17%程度に分散する）。
2. **否決の代償が最大**。他人の裏切りに賭ける自己反対は -100 を招く。

第10ラウンドで、自己反対より優れた解（**自分が決定票になる最小連合を提案する**）が
あることを示した。この洗練された解にたどり着くには、
**提案側の十分な学習量**と**リスクを避ける強い動機**の両方が要る。
**その両方が揃うのは一強・L=100 だけ**であり、そこでだけ自己反対が消える。

これは第10ラウンドで未検証としていた解釈（均等では提案者が毎回替わるため
提案の設計を洗練させられない）と整合する。ただし**依然として解釈であり、
直接検証したわけではない。**

### 均等・L=100 では自己反対しても罰を消しきれていない

試行47 の自己反対は、他の3セルと比べて**効果が不完全**である。

| 試行 | 構成 | 自己反対率 | **払われた罰/エピソード** | 超過票の分布 |
|---|---|---|---|---|
| 46 | 一強・L=5 | 98.0% | **0.00** | すべて 0 |
| 45 | 均等・L=5 | 38.0% | **0.00** | ― |
| **47** | **均等・L=100** | **62.0%** | **0.62** | 0 が8件・**1 が12件** |

詳細ログでは、自己反対した12件すべてが **賛成4票／生存6人**（必要3票）である。
提案者が反対しても**なお1票余っている。**

```
提案 [0, 0, 0, 3, 2, 0]   ← D は3個を自分に、E に2個
（D は最後に 👎 反対）→ 賛成4 / 生存6 → 可決、超過票 1
```

買収は1人だけなのに、**宝石を受け取らない3人が賛成している。**
無償の賛成票が多すぎて、提案者が1票減らしても超過が残る。

**自己反対率が高いことと、罰を回避できていることは別物である。**
試行45 は自己反対38%で罰ゼロ、試行47 は自己反対62%で罰0.62 と、
両者の順序は逆転している。指標としては
**「自己反対率」ではなく「実際に払われた罰」を見る必要がある。**

## 試行48: L=5・均等・観測のみ

### 18.0%。自己反対したのは「最後に投票する F」だけだった

**自己反対率は 18.0%（18/100）。** 投票順を従来のままにすると、
試行45（38.0%）の半分以下になる。

そして**誰が自己反対したかが決定的な手がかりになった。**
評価100エピソードすべての詳細ログを取り直して集計した結果:

| 自己反対した提案者 | 件数 |
|---|---|
| **agent_F** | **18件** |
| 他の5体（A〜E） | **0件** |

`result_48.txt` では **F の提案回数はちょうど18回**である。
つまり **F は自分が提案したとき必ず自己反対し、他の5体は一度もしない。**

**F は固定順（A, B, C, D, E, F）で最後に投票するエージェントである。**
F が提案者のとき、F は他の5人全員の票を見てから自分の票を決められる。
他の5体は自分より後に投票する者がいるため、票が確定していない。

### 必要なのは「票が見える位置で投票できること」

第10ラウンドでは `proposer_votes_last` が「単独では無効」だと結論した。
本試行と合わせると、より正確な条件が見える。

**自己反対には、提案者が (1) 票数を観測でき、かつ (2) 十分に遅く投票する
ことの両方が要る。**

| 試行 | 観測 | 提案者の投票位置 | 自己反対率 |
|---|---|---|---|
| 42 | なし | 最後 | **0.0%** |
| 44 | あり | 最初（一強の A） | **0.0%** |
| **48** | **あり** | **F のみ最後** | **18.0%（全件 F）** |
| 45 | あり | 全員最後 | 38.0% |
| 46 | あり | 全員最後 | 98.0% |

- **観測がなければ、位置が最後でも無意味**（42）。見えないものは使えない。
- **観測があっても、最初に投票するなら無意味**（44）。見るべき票がまだない。
- **両方揃った提案者だけが自己反対する**（48 の F）。

第10ラウンドで「`proposer_votes_last` は本ラウンドを通じて一度も必要なかった」と
書いたが、これは**一強構成に限った話**だった。一強では提案の9割を担う A が
最初に投票するので、`proposer_votes_last` を入れないと条件(2)が満たされない。
試行44 で効果が出たのは、A ではなく**投票者側**の観測が効いたためであり、
自己反対とは別の経路だった。

### 均等・L=5 では、能力が上がるほど罰が消える

同じ「罰1.0・L=5・均等」で、与えた能力だけが異なる3本が揃った。

| 試行 | 観測 | 投票順 | 自己反対率 | **払われた罰/エピソード** |
|---|---|---|---|---|
| 40（第9ラウンド） | なし | 従来 | **0.0%** | **0.47** |
| **48** | **あり** | 従来 | **18.0%** | **0.16** |
| 45（第10ラウンド） | あり | 最後 | **38.0%** | **0.00** |

**自己反対できる提案者が増えるほど、罰は単調に消えていく。**
罰則の効き目は、エージェントが持つ観測と手番の構造で決まる。

## 第11ラウンドの統合結論

### 1. 自己反対の出現は L と権力構造の交互作用で決まる

| | **一強** | **均等** |
|---|---|---|
| **L=100** | **0.0%**（試行43） | **62.0%**（試行47） |
| **L=5** | **98.0%**（試行46） | **38.0%**（試行45） |

L 単独でも権力構造単独でも説明できない。一強では L が決定的だが（0→98%）、
均等では向きが逆転し幅も小さい（62→38%）。

**現れないのは「一強かつ L=100」の1セルだけ**である。
このセルだけが、提案側の学習信号が1体に集中し（A が提案の9割）、
かつ否決の代償が最大になる。第10ラウンドで示した**より優れた解**
（自分が決定票になる最小連合の提案）にたどり着くには、
**十分な学習量とリスク回避の動機の両方**が要り、
それが揃うのはこのセルだけと解釈できる。ただし直接検証はしていない。

### 2. 自己反対には「票が見える位置で投票できること」が要る

観測だけでも投票順だけでも足りない。両方が揃った提案者だけが自己反対する。
試行48 の F（固定順で最後に投票する唯一の提案者）が18回中18回、
他の5体が0回という結果が、これを個体単位で示している。

### 3. 「自己反対率」は罰の回避を測る指標にならない

| 試行 | 自己反対率 | 払われた罰/エピソード |
|---|---|---|
| 45 | 38.0% | **0.00** |
| **47** | **62.0%** | **0.62** |

順序が逆転する。試行47（均等・L=100）では、宝石を受け取らない agent が
無償で賛成しすぎるため、提案者が1票減らしても超過が残る。
**評価は「実際に払われた罰」で行うべきである。**

### 4. 自己反対は最善手ではない

同じ L=5・一強で比較すると、環境設定のない試行37 の方が A の取り分が多い。

| | 試行37（設定なし） | 試行46（順番＋観測） |
|---|---|---|
| A の平均報酬 | **+2.88**（宝石3個・買収2人・賛成） | +1.80（宝石2個・買収3人・**反対**） |
| 払われた罰 | ほぼ 0 | 0.00 |

どちらも罰はゼロだが、**買収2人＋自分の賛成の方が、買収3人＋自分の反対より安い。**
自己反対を可能にすると、学習は**劣った解に落ち着いた。**

### 5. 保存モデルの修正が機能している

第10ラウンド末に修正した保存処理により、試行48 のモデルを読み直した再評価が
**原著と同じ 18.0%（18/100）を再現した。** 学習をやり直さずに
`scripts/reevaluate.sh` で詳細を掘れるようになっている
（試行45 以前のモデルは空のままで、再評価できない）。
