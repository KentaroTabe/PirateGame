# 第9ラウンド実験レポート: 過剰賛成票ペナルティの検証（試行37〜40）

## 目的と設計

事前実験（[`round0.md`](round0.md)）で、**可決時に必要最小票を超えた賛成1票に
つき提案者の報酬から引く**というペナルティ（`excess_vote_penalty`）を課すと、
**提案者が自分の提案に反対票を投じる**という異常行動が観察されたと記録されている。
海賊ゲームでは提案者も投票者の一人なので、自分が反対に回れば超過分を1票減らして
ペナルティを軽減できるためである。

現在のパイプラインでは、この設定は**全40試行で 0.0 のまま一度も検証していない**
（固定順一般解がこのペナルティを想定していないため、事前学習と整合させる目的で
無効にしていた）。第9ラウンドでこれを検証する。

| 試行 | ペナルティ | L | 重み | 狙い |
|---|---|---|---|---|
| 37 | **1.0** | 5 | 一強 | 異常行動が再現するか（方策が最も安定する L=5 で） |
| 38 | **2.0** | 5 | 一強 | ペナルティを強めると行動も強まるか |
| 39 | **1.0** | 100 | 一強 | 高罰則域でも現れるか |
| 40 | **1.0** | 5 | 均等 | 権力構造によらず現れるか |

共通設定: 事前学習なし、7000エポック、メトリクス評価100エピソード、シード42。
比較の基準は試行29（ペナルティ 0.0・L=5・一強・シード42）である。

### 計測系の追加

異常行動を目視ではなく数値で捉えるため、`eval.py` に
**「提案者が自分の提案に投じた票」の集計**を追加した。
評価100エピソードを通じて「提案者が自分の提案に反対した割合」を
`result/result_n.txt` に記録する。ペナルティ 0.0 の設定では
0% になるはずであり、そこからの乖離が異常行動の強さになる。

生データ: `result/result_37.txt` 〜 `result_40.txt`、
`log/log_eval_37.txt` 〜 `40`（投票の詳細ログ）、
`log/log_metrics_37.csv` 〜 `40`。

## 試行37: ペナルティ1.0・L=5・一強

### 異常行動はほとんど再現しなかった

**提案者が自分の提案に反対した割合は 1.9%（2/106）**にとどまった。
事前実験で記録された「提案者が自分の提案に反対する」という顕著な行動は、
少なくともペナルティ1.0・L=5・一強の条件では再現していない。

なお比較対象の試行29 は本指標の追加前に実行したため、
**ペナルティ 0.0 での自己反対率は未測定**である。1.9% がペナルティに
由来するのか元々の雑音なのかは、この試行だけでは切り分けられない。

### 予期しなかった効果: ペナルティが独裁者を富ませた

同一条件でペナルティのみを変えた試行29 との比較。

| 指標 | 試行29（罰 0.0） | 試行37（罰 1.0） |
|---|---|---|
| **A の平均報酬** | **+1.82** | **+2.88** |
| A の提案回数（可決率） | 90回（100%） | 96回（100%） |
| C の平均報酬 / 死亡率 | +1.00 / 0.0% | **-0.18 / 4.0%** |
| F の平均報酬 / 死亡率 | +0.94 / 0.0% | **-0.10 / 2.0%** |
| C・F の提案の可決率 | 100% | **0%** |
| 平均提案回数 | 1.00 | 1.06 |

**超過賛成票を罰する規則が、最強の提案者 A の取り分を +1.82 から +2.88 へ
1個以上増やした。** 詳細ログ（3エピソード分）で機構が確認できる。

| | 試行29（罰 0.0） | 試行37（罰 1.0） |
|---|---|---|
| A が自分に取る宝石 | 2個 | **3個** |
| A が買収する人数 | 3人 | **2人** |
| 可決時の超過賛成票 | 0 | 0 |

A は罰則下で**買収相手を3人から2人に絞り、浮いた1個を自分の取り分にした**。
過剰な支持を罰する規則は、提案者に「最小限の連合だけを買え」と教え、
その節約分はそのまま提案者の懐に入る。**支持の買い占めを抑制する規則が、
むしろ独裁者の分け前を増やす方向に働いた。**

同時に、ほとんど提案しない C と F は提案がすべて否決されるようになり
（可決率 100% → 0%）、死亡率が 0.0% から 4.0% / 2.0% に上がって
平均報酬がマイナスに転じた。

> **追記（試行38 の後）**: この C・F の悪化は**罰則の効果ではなかった**。
> 罰を 2.0 に強めた試行38 では死亡率が全員 0.0%、可決率も全員 100% に戻る。
> 罰 0.0 → 1.0 → 2.0 で悪化が現れて消えるのは系統的な効果ではなく、
> **提案をほとんど担っていないエージェントの試行間のばらつき**である
> （第8ラウンド 試行36 で確認した性質と同じ）。

ただし超過賛成票は両条件とも 0 であり、**罰則は実際にはほとんど発動していない**
（詳細ログ3エピソードの範囲）。差は罰を受けた結果ではなく、
罰を避けるように方策が変わった結果である。

## 試行38: ペナルティ2.0・L=5・一強

### 罰を倍にしても異常行動は増えず、むしろ 0 になった

**自己反対率は 0.0%（0/100）。** 罰 1.0 の試行37 では 1.9%（2/106）だったので、
**罰を強めるほど自己反対が増える、という関係は成り立たない。**
事前実験の知見1 は、罰の強さ 1.0・2.0 のいずれでも再現しなかった。

### 富の移転は罰の強さに比例しない（飽和する）

| ペナルティ | 0.0（試行29） | 1.0（試行37） | 2.0（試行38） |
|---|---|---|---|
| **A の平均報酬** | +1.82 | **+2.88** | **+2.70** |
| A が自分に取る宝石 | 2個 | 3個 | 3個 |
| A が買収する人数 | 3人 | 2人 | 2人 |
| 可決時の超過賛成票 | 0 | 0 | 0 |
| 全員の死亡率 | 0.0% | C 4.0% / F 2.0% | **全員 0.0%** |
| 提案の可決率 | 全員 100% | C・F が 0% | **全員 100%** |

**効果は罰の強さに比例せず、0 と正の値の間で一度だけ切り替わる。**
A は罰が入った時点で最小連合（自分＋2人）に切り替わり、そこから先は
削る相手がいない。罰を倍にしても方策は同じで、報酬もほぼ横ばい
（+2.88 と +2.70 の差は試行間のばらつきの範囲）。

この飽和には明快な理由がある。**超過賛成票は3条件すべてで 0 であり、
罰則は一度も発動していない。** 発動しない罰の大きさは報酬に影響しない。
罰が効いているのは金額としてではなく、**学習中に「最小連合を買え」と
方策を切り替えさせる閾値としてのみ**である。

### 試行37 の C・F 悪化は罰の効果ではなかった

試行37 で観察した C・F の死亡率上昇と可決率の低下は、罰をさらに強めた
試行38 で完全に消える（全員 死亡率 0.0% / 可決率 100%）。
罰 0.0 → 1.0 → 2.0 で悪化が現れて消えるのは系統的な効果ではありえない。
**提案をほとんど担っていないエージェントの指標は試行間で大きくばらつく**
という第8ラウンド 試行36 の知見が、報酬側の指標にも当てはまることを示している。

## 試行39: ペナルティ1.0・L=100・一強

### 罰が初めて実際に発動した。それでも自己反対は 0%

**自己反対率は 0.0%（0/100）。** しかも本試行は、第9ラウンドで**唯一
罰則が実際に発動している条件**である（可決時の超過賛成票が 2）。

これは最も厳しい反証条件にあたる。A は5票の賛成を得て可決しており、
必要票は3である。**A が自分の提案に反対しても yes は 4 で可決し、
超過分が1減って罰を1つ軽くできる。** それでも A は反対しない。
**罰を実際に払っている状況で、直接得をする自己反対を学習していない。**

### L が罰の効果を反転させる

同じ罰 1.0 で L だけを変えた比較。

| | L=5（試行37） | L=100（試行39） |
|---|---|---|
| **A の平均報酬** | **+2.88** | **-1.80** |
| A が自分に取る宝石 | **3個** | **0個** |
| A が買収する人数 | **2人** | **4人** |
| 可決時の超過賛成票 | 0 | **2** |
| A の死亡率 | 0.0% | 0.0% |

**同じ罰則が、L によって正反対の行動を生む。**

- **L=5**: 否決されても -5 なので、A は罰を避けて**最小連合に絞り**、
  宝石を3個抱え込む（+2.88）。
- **L=100**: 否決されれば -100 なので、A は**全宝石5個を配って4人を買収し**、
  過剰な5票で確実に可決させる。罰 -2 を保険料として払い、
  自分の取り分は 0、報酬は **-1.80 とマイナスに沈む**。

死の恐怖が罰則を圧倒する。**A は「確実な -2」を選んで「わずかな確率の -100」を
避けている。** 罰則は L=5 では独裁者を富ませ、L=100 では独裁者に
保険料を払わせる。**罰則の符号は L が決める。**

### 事前実験の「現存する痕跡」は自己反対の証拠ではなかった

[`round0.md`](round0.md) の知見1 は、投票単位のログが残っていないため、
L=100 で -1.0 / -2.0 という小さな負の報酬が記録されている点を
**自己反対行動の現存する痕跡**として挙げていた（試行15・27・33）。

本試行はその条件（6人・L=100・罰1.0）に最も近く、**同じ数値的特徴を再現する**
（A: -1.80、超過票 2）。しかし**自己反対率は 0.0% である。**

**したがって、あの小さな負の報酬は自己反対の証拠にならない。**
提案者が死を避けるために支持を買い過ぎれば、自己反対が一切なくても
同じ痕跡が残る。知見1 の一次記録が現存しない以上、
**あの痕跡から自己反対を推認することはできない。**

### なぜ学習されないのか（構造的な理由）

環境の作りから、自己反対は**常に盲目の賭け**になる。

1. **観測に投票の途中経過が入っていない。** 観測は
   `生存フラグ + 権力ウェイト + 提案者one-hot + 分配案` のみで
   （[env.py:120](env.py:120)）、他者が何票入れたかは分からない。
2. **提案者 A は最初に投票する。** 投票順は生存者を固定順（A, B, C…）に
   並べたもので（[env.py:145](env.py:145)）、A は提案者である90%の場合、
   誰の票も見ないうちに自分の票を決める。

つまり自己反対は「他者が十分賛成してくれる」と賭けたうえでの無条件行動であり、
外せば -L を負う。L=100 ではこの賭けの期待値が極端に悪い。
**罰を1つ軽くするために -100 の危険を冒す方策は学習されない。**

なお、この観測の作りは事前実験当時（`5a47625:env.py:104`）と**同一**であり、
当時と現在の違いを説明するものではない。自己反対が学習されにくい
構造的な理由を示すにとどまる。

6体すべて完全に一致**しており（10・16・17・19・20・18回）、
提案者の並びまで同じで、罰の有無だけが違う対照になっている。

| エージェント | 提案回数 | 試行30（罰 0.0） | 試行40（罰 1.0） |
|---|---|---|---|
| A | 10回 | +0.39 | +0.47 |

| C | 17回 | +0.70 | +0.54 |
| D | 19回 | +0.81 | +0.72 |
| E | 20回 | +0.85 | +0.30 |
| F | 18回 | +1.01 | +1.08 |
| **合計** | | **5.00** | **4.53** |

死亡は両者とも 0.0%、平均提案回数も 1.00 なので、**報酬の合計は

## 第9ラウンドの統合結論

### 1. 事前実験の異常行動は再現しなかった

4条件すべてで自己反対はほぼ 0 である。

| 試行 | 罰 | L | 重み | **自己反対率** | 1エピソードあたり実際に払われた罰 |
|---|---|---|---|---|---|
| 37 | 1.0 | 5 | 一強 | **1.9%**（2/106） | ほぼ 0（死亡があり厳密には分離不可） |
| 38 | 2.0 | 5 | 一強 | **0.0%**（0/100） | **0.00** |
| 39 | 1.0 | 100 | 一強 | **0.0%**（0/100） | **1.96** |
| 40 | 1.0 | 5 | 均等 | **0.0%**（0/100） | **0.47** |

合計 **2/406 提案 = 0.5%**。罰の強さ（1.0・2.0）、L（5・100）、
権力構造（一強・均等）のいずれを変えても現れない。

**しかもこれは「罰が効いていないから」ではない。** 試行39 では毎エピソード
約2、試行40 では約0.47 の罰が実際に支払われている。
**罰を現に払っている状況ですら、提案者は自分の提案に反対しない。**

試行39 は最も厳しい反証条件だった。A は5票で可決しており必要票は3なので、
**自分が反対しても可決は保たれたまま罰が1つ軽くなる。**
それでも反対しない。

### 2. round0 の知見1 は根拠を失った

[`round0.md`](round0.md) は、投票単位のログが現存しないことを認めたうえで、
L=100 で -1.0 / -2.0 という小さな負の報酬が残っている点を
自己反対の**現存する痕跡**として挙げていた。

試行39 は同じ条件（6人・L=100）で**同じ数値的特徴を自己反対 0% のまま
再現した**（A: -1.80、超過票 2）。提案者が死を避けて支持を買い過ぎれば、
自己反対が一切なくても同じ痕跡が残る。
**あの痕跡から自己反対を推認することはできない。**

知見1 は「当時そう観察された」という記録としては残るが、
**現存する証拠に裏づけられた主張ではない。**

### 3. なぜ学習されないのか（構造的な理由）

環境の作りから、自己反対は**常に盲目の賭け**になる。

1. **観測に投票の途中経過が入っていない**（[env.py:120](env.py:120)）。
   他者が何票入れたかは分からない。
2. **提案者は固定順（A, B, C…）の自分の位置で投票する**
   （[env.py:145](env.py:145)）。一強構成では提案の9割を担う A が
   **誰の票も見ないうちに**自分の票を決める。

自己反対は「他者が十分賛成してくれる」に賭けた無条件行動であり、
外せば -L を負う。この観測の作りは事前実験当時と同一
（`5a47625:env.py:104`）なので、当時と現在の違いは説明しない。
**学習されにくい構造的な理由を示すにとどまる。**

### 4. 副産物: L が罰則の符号を決める

本来の目的ではないが、明確な結果が出た。同じ罰 1.0 で L だけを変えると
提案者の行動が正反対になる。

| | L=5（試行37） | L=100（試行39） |
|---|---|---|
| **A の平均報酬** | **+2.88** | **-1.80** |
| A が自分に取る宝石 | 3個 | **0個** |
| A が買収する人数 | 2人 | **4人** |

- **L=5**: 否決の代償が小さいので、A は罰を避けて最小連合に絞り、
  宝石を抱え込む。**罰則が独裁者を富ませる**（罰なしの +1.82 から +2.88 へ）。
- **L=100**: 否決されれば -100 なので、A は全宝石を配って4人を買収し、
  過剰な5票で確実に可決させる。**罰 -2 を保険料として払い、報酬はマイナスに沈む。**

**A は「確実な -2」を選んで「わずかな確率の -100」を避けている。**
過剰な支持を罰する規則は、L が小さければ独裁者の取り分を増やし、
L が大きければ独裁者に保険料を払わせる。

### 5. 効果は罰の強さに比例しない

罰 1.0 と 2.0（試行37・38）で A の方策は同一（最小連合・宝石3個）、
報酬も +2.88 と +2.70 でほぼ変わらない。
L=5 では超過票が 0 になるため**罰は一度も発動せず**、その大きさは
報酬に影響しない。**罰が効いているのは金額としてではなく、
学習中に方策を切り替えさせる閾値としてのみである。**

### 6. 弱い個体の指標は罰の効果を語れない

試行37 で C・F の死亡率が上がり可決率が 0% に落ちたが、
罰をさらに強めた試行38 では全員が死亡率 0.0% / 可決率 100% に戻る。
罰 0.0 → 1.0 → 2.0 で悪化が現れて消えるのは系統的な効果ではありえない。
**提案をほとんど担わない個体の指標は試行間で大きくばらつく**という
第8ラウンド 試行36 の知見が、報酬側の指標にも当てはまる。

## 次のラウンドの候補

自己反対が現れないことは4条件で確認できたが、**それが報酬設計のせいなのか
環境の作りのせいなのかは分離できていない。** 上記3の構造的理由が正しければ、
以下を変えると現れるはずである。

1. **提案者を最後に投票させる**（投票順を「提案者以外 → 提案者」にする）。
   提案者は他者の票数を見てから決められるので、賭けではなくなる。
2. **観測に投票の途中経過を入れる**。1 の効果を条件付けとして学習できる形にする。

どちらも環境の変更なので、既存の全試行との比較可能性を壊す。
実施する場合は既存設定との対照を同時に走らせる必要がある。
