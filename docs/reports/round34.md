# 第34ラウンド実験レポート: 否決の罰の効果を要因分解する

[`proposal.md`](../proposal.md) の本実験である。
**本書の「事前登録」の節は、学習を起動する前にコミットした。**

## 目的

L=5 と L=100 の差 D が、否決された提案者の脱落から来るのか、報酬の絶対的な桁から来るのかを調べる。

## 設計

| 要因 | 水準 |
|---|---|
| 脱落 | あり／なし（否決された提案者は -L を負って残り、提案回数の上限は5回） |
| L | 5／100 |
| 報酬の縮尺 | なし／1/L 倍 |

共通: 6体・宝石5個・一強 `[50,1,1,1,1,1]`・罰0.0・票数観測なし・事前学習なし・7000エポック。
シードは 42・7・13・99・1・2・3・4 の8個で、計64本である。

- 脱落あり・縮尺なしの16本は、既存の試行と同じ設定を学習中の記録つきで再実行する。
  決定性が保たれていれば、最終の一致率は既存の値と一致する。
- 脱落なしの環境では割引を使わない（δ=1）。脱落ありのゲームにも割引がなく、
  比べる要因を脱落に絞るためである。上限5回は脱落ありの最大提案回数に合わせた。
- 脱落なしの環境の基準は `solver.NoEliminationSolver` である。理論均衡は L で変わらない。

## 事前登録

### 指標と判定

主指標は全局面の投票の均衡一致率（どちらかの同点規則に一致）である。
`scripts/analyze_r34.py` で次の対比を求める。

| 対比 | 定義 |
|---|---|
| C1 脱落の効果 | D(脱落あり・縮尺なし) − D(脱落なし・縮尺なし) |
| C2 縮尺の効果 | D(脱落あり・縮尺なし) − D(脱落あり・縮尺あり) |
| C3 交互作用 | C1 − [D(脱落あり・縮尺あり) − D(脱落なし・縮尺あり)] |

- 区間は復元抽出10000回のパーセンタイル区間で、信頼水準は 1−0.05/3 とする。
- **区間が0を含まなければ効果ありとする。**
- 脱落の有無で全局面の集合が変わるので、**C1 と C3 は初回局面の一致率でも同じ判定を行う。**
  両者で符号か判定が食い違う場合は「確立しない」とする。
- 到達局面の一致率の学習後半の平均と、A の報酬の分解は副指標で、判定には使わない。

### 予測

1. 脱落なしでも D は正のまま残る（否決の罰は残るため）。
2. C1 は正になる（脱落をなくすと D は縮む）。確信度は低い。
3. C2 の区間は0を含む（全報酬の定数倍では宝石と罰の比が変わらないため）。
4. C3 の区間は0を含む。

### 解釈の限界

全報酬の 1/L 倍は、宝石1個と罰の比を変えない。したがって C2 で確かめられるのは
**報酬の絶対的な桁の影響だけ**である。D が残っても、罰と宝石の桁の差が学習を乱す可能性は否定できない。
その検証には、提案と投票のネットワークの分離など別の操作が要る。

検出力の見積もりは既存の2セルの少ない実測値によるもので、新しい3条件のばらつきは未知である。
