# 実験レポート: ベースライン — 二頭+平民型 `[10, 15, 2, 1, 1, 1]`（試行6）

## 実験概要

| 項目 | 値 |
|---|---|
| 権力ウェイト | `[10, 15, 2, 1, 1, 1]`（A:10, B:15, C:2, D:1, E:1, F:1） |
| 提案機会の期待割合 | A 33% / B 50% / C 7% / D・E・F 各3% |
| 命の重さ L | 100 |
| 学習エポック | 10000 |
| 生データ | `result/result_6.txt`, `log/log_eval_6.txt`, `log/log_metrics_6.csv` |
| 学習曲線 | `files/plots/log_metrics_6.png` |

構図: 提案権をほぼ独占する二大権力（A・B）と、めったに提案できない平民層（D・E・F）、
中間の C という「二頭政治」型。

## 評価結果（100エピソード・貪欲方策）

| エージェント（重み） | 平均報酬 | 死亡率 | 提案回数（可決率） |
|---|---|---|---|
| A (10) | +1.18 | 0% | 26回 (100%) |
| B (15) | +1.14 | 0% | 56回 (100%) |
| C (2)  | +0.40 | 0% | 6回 (100%) |
| D (1)  | +1.06 | 0% | 4回 (100%) |
| E (1)  | +0.26 | 0% | 6回 (100%) |
| F (1)  | +0.96 | 0% | 2回 (100%) |

全エピソードが一発可決（平均提案回数 1.00）。

## 学習された提案

- **B の提案**: `[1, 2, 0, 1, 0, 1]` — 自分に2個、A・D・F に1個ずつ
- **A の提案**: `[2, 0, 0, 1, 1, 1]` — 自分に2個、D・E・F に1個ずつ

提案者は2個を確保し、残り3個で3票を1個ずつ買う「連立買収」型。

## 考察

- **権力と取り分の相関は弱い**。提案機会50%の B と3%の D の平均報酬差はわずか
  0.08。提案権の価値（自分に2個）はあるが、支配には遠い。
- **「安い票」の地位が創発**。D・F は A・B 両方の連立に入っており、
  自分ではほぼ提案できないのに報酬上位。C・E は片方の連立
  （E は A 陣営のみ、C はどちらからも0個）から漏れて最下位。
  **取り分を決めるのは自分の権力ではなく「どの連立に買われるか」**。
- **A・B 間の非対称**: B は A に1個渡す（宥和）が、A は B に0個（無視）。
  1000エポック時点（試行5）に存在した「A ヘゲモニー」（A 全取り、
  B が A に朝貢）の名残とも、B の票が高くつくための合理的排除とも
  解釈できる（切り分けは未確認）。
- **静的な均衡には収束しない**。10000エポック時点でも周期的な体制動揺が残る
  （エポック8800-9400に A の死亡期、9500に B の死亡率57%の危機）。
  評価統計は「平和な瞬間のスナップショット」。

試行5（1000エポック）との比較の詳細は [`../findings.md`](../findings.md) を参照。
