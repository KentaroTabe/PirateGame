## 学習された提案

- **A の提案**: `[4, 0, 1, 0, 0, 0]` — 自分に4個、**C に1個だけ**

宝石5個の80%を自分に。買収は単一の子飼い（C）1人のみ。

## 考察

- **独裁は最も収奪的で、かつ最も安定**。A は宝石の8割を恒常的に取り、
  序盤の1回の危機（エポック1000〜1700に A の死亡率13%・報酬-80級の
  反乱期）を鎮圧した後は、死亡率ほぼ0%・一発可決率ほぼ100%の
  「パクス・ディクタトリア」が10000エポックまで続く。
  ベースライン（二頭型）で周期的に起きた体制動揺は消滅した。
- **収奪を可能にするのは投票力ではなく議題設定権の独占**。A の票は
  依然1票だが、他者が提案者になる機会（=否決後の継続価値）が
  ほぼゼロのため、全員の「反対する価値」が消滅し、票がタダ同然になる。
  ベースラインの提案者が2個しか取れず3票を買っていたのに対し、
  A は4個取って1票しか買わない。**再交渉の見込みが消えると
  交渉力も消える**ことの端的な実例。
- **単一の子飼い（C）だけが分け前を得る**。C 以外の平民（B・D・E・F）は
  ほぼ0個でも賛成する。宮廷における寵臣の構図に近い。
- 学習後半では A の取り分がさらに漸増しており（宝石レンジ拡大パネルで
  約2.0 → 3.0）、**独裁の学習は「徐々に大胆になる」方向に単調**。
  終盤10%区間の平均でも A +2.71 で、F は -0.03 とわずかに死亡が出る程度。
- 実行時間は約3.4時間（15:24〜18:49）。
