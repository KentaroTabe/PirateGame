# 実験レポート: 後継者あり一強 `[50, 25, 1, 1, 1, 1]`（試行12）

## 実験概要

| 項目 | 値 |
|---|---|
| 権力ウェイト | `[50, 25, 1, 1, 1, 1]`（A が最強、**B が有力な後継者**） |
| 提案機会の期待割合 | A 65% / B 32% / C〜F 各1.3% |
| 事前学習 | あり（試行8と同条件） |
| 命の重さ L | 100 |
| 学習エポック | 7000 |
| 生データ | `result/result_12.txt`, `log/log_eval_12.txt`, `log/log_metrics_12.csv` |
| 学習曲線 | `files/plots/log_metrics_12.png` |

**検証する仮説**: 試行8（`[50,1,1,1,1,1]`）で A が宝石の8割を収奪した。
これは「A の権力が絶対的だから」ではなく「A を否決しても次に提案できる者が
いないから（後継候補の不在）」ではないか。A の重みを50に固定したまま
B を25に上げ、有力な後継者だけを追加して検証する。

## 評価結果（100エピソード・貪欲方策）

収束しない実験系のため3つの指標を併記する。**死亡込みの全期間平均**が
長期的な立場を最もよく表す（死亡なし記録点の平均は、頻繁に死ぬ
エージェントほど罰を受けた区間が除外されて有利に見えるため）。

| エージェント（重み） | 最終評価 | 死亡なし記録点の平均 | **全期間平均（死亡込み）** | 提案回数（可決率） |
|---|---|---|---|---|
| A (50) | +0.01 | +1.23 | **-2.16** | 60回 (100%) |
| B (25) | +1.21 | +0.68 | **-0.20** | 36回 (100%) |
| C (1)  | +0.65 | +0.96 | +0.87 | 2回 (100%) |
| D (1)  | +1.02 | +0.90 | **+0.91** | 0回 (---) |
| E (1)  | +0.37 | +0.64 | +0.63 | 1回 (100%) |
| F (1)  | **+1.74** | +0.59 | +0.66 | 1回 (100%) |

**権力を持つ2人（A・B）だけが長期でマイナス**、無力な4人は全員プラス。

## 学習された提案

- **A の提案**: `[0, 2, 1, 1, 0, 1]` — **自分に0個**、B に2個・C に1個・D に1個・F に1個
- **B の提案**: `[0, 0, 0, 1, 1, 3]` — **自分に0個**、D に1個・E に1個・F に3個

提案権を持つ両者とも、自分の取り分をゼロにして5個すべてを配っている。
可決に必要なのは2票だけなのに4人に配る「過剰譲歩」。

## 試行8（後継者なし・同じ A の権力）との対照

| | 試行8 `[50,1,1,1,1,1]` | 試行12 `[50,25,1,1,1,1]` |
|---|---|---|
| A の提案 | `[4,0,1,0,0,0]`（**自分に4個**） | `[0,2,1,1,0,1]`（**自分に0個**） |
| A の全期間平均 | **+1.18**（1位） | **-2.16**（**最下位**） |
| A の死亡危機 | 序盤に1回 | **5回**（死亡率12〜13%級） |
| 事前学習 | あり | あり（同条件） |

A の権力（重み50）も事前学習も同じで、**B を後継者に据えたことだけが違う**。
それだけで A の提案は「自分に4個」から「自分に0個」へ反転した。

### 学習長の交絡の確認

試行8は10000、試行12は7000エポックだが、試行8の A はエポック500頃から
一貫して首位で7000時点でも平滑報酬 +2.5〜3.0 に達していたため、
同じ7000で比べても結論は変わらない。

## 考察

- **仮説は支持された**。収奪を可能にしていたのは権力の絶対量ではなく
  **後継候補の不在**である。A の重みを50に保ったまま有力な後継者 B を
  置くだけで、A は宝石を1個も確保できなくなった。
  否決後に B が提案者になる見込みが立つと、各投票者の継続価値
  （＝拒否の脅しの信用）が回復し、A は票を買うために全額を
  差し出さざるを得ない。
- **権力は L=100 では純粋な負債である**。提案権の97%を握る A と B が
  長期平均でマイナス（-2.16 / -0.20）、ほぼ提案できない C〜F が
  全員プラス（+0.63〜+0.91）という完全な逆転が生じた。
  提案は否決一発で -100 を負う行為であり、提案機会が多いほど
  死の期待値が積み上がる。試行9（階段重み）で見た逆転が、
  より極端な権力集中でも成立する。
- **後継者自身も守られない**。B は A から2個を受け取る立場でありながら、
  自分が提案するときは自分に0個しか残さず、エポック5750〜6400には
  B 自身の死亡危機も起きている。**「次の提案者になれる」という地位は
  票としての価値を高めるが、提案者としての安全は保証しない**。
- **指標の選び方で結論が反転する**。A は最終評価で +0.01、死亡なし記録点の
  平均では **+1.23（1位）**、死亡込みの全期間平均では **-2.16（最下位）**。
  死亡なし記録点の平均は A が罰を受けていた区間をまるごと除外するため、
  頻繁に死ぬエージェントを過大評価する。この実験系では
  **死亡込みの全期間平均で読むべき**である。
- 振動は変わらず継続（首位交代28回、レジーム・秩序とも未収束）。
