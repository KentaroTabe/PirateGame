# 第6ラウンド実験レポート: 撤回した主張の決着と新仮説の検証（試行25〜28）

## 目的と設計

第5ラウンド（[`round5.md`](round5.md)）では、L=50 の再現実験によって
**同一設定でも量が大きくばらつく**ことが判明し、各 L につき1本で語っていた
閾値の主張を撤回した。本ラウンドは**未決着の主張に決着をつける**ことを
主目的とし、あわせて新仮説を最も有利な条件で試す。

| 試行 | 設定 | 狙い |
|---|---|---|
| 25 | **L=20・シード7**（試行18の再現） | L=20 の未収束はシード依存か |
| 26 | **L=30・シード7**（試行22の再現） | L=30 の収束は本物か |
| 27 | **L=10・一強・シード7**（試行20の再現） | 新仮説が依存する「強い収束」の再現 |
| 28 | **L=5・均等重み** `[1,1,1,1,1,1]` | 新仮説の反証テスト |

共通設定: 事前学習なし、7000エポック、メトリクス評価100エピソード。
試行25〜27は重み `[50,1,1,1,1,1]`。

### 試行25〜27で決着させたいこと

第5ラウンドまでの収束データは、L ごとに1本しかない点が多かった。

| L | 収束したか | 本数 |
|---|---|---|
| 10（一強） | ✅（首位交代3回） | **1本** |
| 20（一強） | ❌（17回） | **1本** |
| 30（一強） | ✅（9回） | **1本** |

この3点だけで「L=20 は例外」とも「収束性は非単調」とも言えない。
それぞれ2本目を走らせて、単調な閾値・非単調・単なるノイズの
どれなのかを判定する。

### 試行28で反証したいこと

第5ラウンドで「収束には低い L と権力の集中の両方が要る」という仮説を立てた。
均等構造は L=10 で収束しなかったが、一強構成が最も鮮明に収束したのは L=5 である。
**均等構造を L=5 で走らせても収束しなければ**、仮説は強く支持される。
逆に収束すれば、必要なのは L の低さだけで、L=10 では足りなかっただけとなる。

### 試行18（L=20・シード42）との比較

| | 試行18（シード42） | 試行25（シード7） | 再現したか |
|---|---|---|---|
| **首位の交代回数** | **17回** | **16回** | **✅ 再現** |
| **レジーム収束** | **未収束** | **未収束** | **✅ 再現** |
| 秩序収束 | 未収束 | 未収束 | ✅ 再現 |
| A の全期間平均の符号 | 正（+0.99） | 正（+0.27） | ✅ 再現 |
| A の順位 | 2位 | **6位（最下位）** | ❌ 一致せず |
| A の提案 | `[2,1,0,1,0,1]` | `[2,0,1,0,1,1]` | ✅ 一致（自分に2個・3人に1個ずつ） |
| 死亡を含む記録点 | 24% | 29% | ✅ 同程度 |

### 考察: L=20 の未収束は本物だった

- **L=20 が収束しないことは再現した**（首位交代17回と16回、
  レジームは2本とも未収束）。シードの引きではない。
- したがって、**L=30 の収束が再現すれば「収束性は L に対して非単調」が
  確定する**（L=10 ✅ → L=20 ❌ → L=30 ✅）。逆に L=30 の収束が
  再現しなければ、非単調に見えたのは L=30 側の偶然だったことになる。
  次の試行26が決め手になる。
- **A の符号は正で再現したが、順位は2位と最下位で一致しなかった**。
  L=20 は A の取り分がほぼ均衡値に近い帯域で、わずかな揺らぎで
  順位が入れ替わる。第5ラウンドで述べた
  「順位と符号は語れるが量は語れない」は、**L=20 付近では
  順位すら語れない**というかたちでさらに厳しくなる。
  語れるのは符号（A は正）と方策の形だけである。
- 提案の中身は一致した（自分に2個・3人に1個ずつ）。
  これで L=5・20・30・50・100 のすべてで同じ形が観測されたことになる。
